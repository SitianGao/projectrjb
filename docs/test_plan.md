# 测试说明书

> **项目**：EduAgent — 基于大模型的个性化学习资源生成与学习多智能体系统
> **测试版本**：v0.1.0

---

## 1. 测试概述

### 1.1 测试目标

本测试计划旨在全面验证 EduAgent 系统的功能完整性、性能表现、内容质量和稳定性，确保系统满足赛题全部需求。

### 1.2 测试范围

| 测试类型 | 覆盖范围 |
|----------|----------|
| 功能测试 | 5 大功能模块：画像构建、路径规划、资源生成、智能辅导、学习评估 |
| 接口测试 | 14 个 API 端点，含 SSE 流式和异步任务 |
| 性能测试 | 响应时间、并发能力、流式首字延迟 |
| 内容质量测试 | AI 生成内容准确性、防幻觉效果、多模态输出 |
| 安全测试 | 内容过滤、敏感词拦截、防注入 |
| 稳定性测试 | 长时间运行、异常恢复、LLM 重试机制 |
| 兼容性测试 | 多浏览器、多设备 |

## 4. 接口测试

### 4.1 API 端点覆盖

| 端点 | 方法 | 测试项 | 预期状态码 |
|------|------|--------|-----------|
| `/` | GET | 健康检查 | 200 |
| `/api/profile/chat` | POST | 正常请求 + 流式 | 200 (SSE) |
| `/api/profile/chat` | POST | 缺少 student_id | 422 或友好错误 |
| `/api/profile/{id}` | GET | 获取已有画像 | 200 |
| `/api/profile/{id}` | GET | 不存在的 ID | 404 |
| `/api/planner/generate` | POST | 正常生成 | 200 (SSE) |
| `/api/resource/generate` | POST | 正常生成 | 200 (task_id) |
| `/api/resource/{id}` | GET | 获取已有资源 | 200 |
| `/api/resource/list` | GET | 带 student_id 查询 | 200 |
| `/api/tutor/chat` | POST | 正常问答 | 200 (SSE) |
| `/api/evaluate/start` | POST | 正常评估 | 200 |
| `/api/evaluate/report/{id}` | GET | 获取评估报告 | 200 |
| `/api/task/{id}/status` | GET | 查询任务进度 | 200 |

### 4.2 错误处理测试

| 测试项 | 预期 |
|--------|------|
| LLM API 超时 | 返回错误码 LLM_TIMEOUT，提示重试 |
| LLM API 不可用 | 自动切换备选模型，不影响用户 |
| 数据库连接失败 | 返回友好错误，不暴露内部异常 |
| 请求体格式错误 | 返回 422 + 明确错误说明 |
| 并发请求 | 多个请求不互相干扰 |

## 5. 性能测试

### 5.1 响应时间

| 指标 | 目标值 | 测试方法 |
|------|--------|----------|
| 对话首字延迟 | ≤ 2 秒 | 计时从发起到第一个 SSE chunk |
| 简单查询（获取画像/路径）| ≤ 1 秒 | 计时 GET 请求完整响应 |
| 资源生成（异步任务）| ≤ 20 秒 | 计时从发起任务到 done |
| 页面首次加载 | ≤ 3 秒 | Lighthouse 性能评分 > 80 |

### 5.2 并发测试

| 指标 | 目标值 | 测试方法 |
|------|--------|----------|
| 3 用户同时对话 | 各会话独立，不串数据 | 开 3 个浏览器窗口同时使用 |
| 5 个资源同时生成 | 任务不互相阻塞 | 连续发起 5 个生成请求 |

### 5.3 流式输出

| 指标 | 目标值 |
|------|--------|
| SSE 连接稳定性 | 不断连 |
| 逐字渲染流畅度 | 无明显卡顿 |
| 长时间流式（>30秒）| 连接保持，不超时 |

## 7. 验收标准

### 7.1 功能验收（对标赛题）

- [ ] 对话式学生画像构建，含 6 个维度，可动态更新
- [ ] 多 Agent 协同架构运行正常（至少 4 个 Agent）
- [ ] 生成至少 5 类学习资源：文档、思维导图、练习题、代码案例、拓展阅读
- [ ] 个性化学习路径规划，含阶段性目标
- [ ] 基于路径的资源推送
- [ ] 智能辅导问答，支持文本和图解
- [ ] 学习效果评估，含进度、掌握度、效率三个维度
- [ ] 评估结果自动调整学习路径和资源（闭环）

### 7.2 非功能验收

- [ ] 流式输出正常，无长时间白屏
- [ ] Markdown 渲染正确（标题、代码块、公式）
- [ ] 多模态内容卡片化展示
- [ ] 内容安全过滤生效
- [ ] 防幻觉机制：不确定内容有标注
- [ ] 开源标注：README 含完整开源致谢清单

### 7.3 性能验收

- [ ] 对话/问答响应 ≤ 5 秒（流式首字 ≤ 2 秒）
- [ ] 多模态生成有进度提示
- [ ] Agent 无依赖时并行处理
- [ ] LLM 调用有失败重试（观察日志）
- [ ] 系统连续运行 1 小时不崩溃

### 7.4 创新点验收

- [ ] 遗忘曲线复习功能可用（或）多解释路径功能可用
- [ ] 设计文档中有创新点的科学问题论证

## 9. 缺陷管理

### 9.1 缺陷等级

| 等级 | 定义 | 处理 |
|------|------|------|
| **P0-致命** | 系统崩溃、核心功能不可用、数据丢失 | 立即修复 |
| **P1-严重** | 功能异常但可绕过、严重影响体验 | Day 16 前修复 |
| **P2-一般** | 边缘情况异常、UI 小问题 | 有时间就修 |
| **P3-建议** | 优化建议、锦上添花 | 不做也行 |
