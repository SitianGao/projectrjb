# 🏗 软件杯A3完整系统架构图（技术展开版）

## 用户/学生
用户通过前端与系统交互，获取个性化多模态学习资源。

---

## 前端层（UI + AI交互 + 可视化 + 状态管理 + 工具链）

### 1️⃣ UI层
- **Ant Design + shadcn/ui** : 基础组件 + ChatGPT风格界面  
- **Tailwind + Framer Motion** : 流式交互 + 微动画

### 2️⃣ 聊天 / AI交互层
- **Vercel AI SDK + react-chat-ui-kit** : 流式生成、多轮对话  
- **socket.io** : 后端实时推送资源

### 3️⃣ 可视化 & 多模态层
- **React Flow** : 学习路径、智能体流程可视化  
- **Echarts / Recharts / Victory** : 学习效果数据可视化  
- **React Player** : 播放生成的视频或动画  
- **Mermaid** : 思维导图 / 流程图  
- **react-markdown / @uiw/react-md-editor** : 渲染文档、题库、PPT内容

### 4️⃣ 状态管理 & 数据层
- **Redux Toolkit / Recoil** : 用户画像、生成资源状态、学习路径  
- **localStorage / sessionStorage** : 临时缓存，加快响应

### 5️⃣ 工具链 & 开发支持层
- **React + Vite + TypeScript** : 前端核心框架  
- **ESLint + Prettier** : 代码规范  
- **Vitest / React Testing Library** : 单元测试  
- **Git + GitHub + CI/CD** : 团队协作和部署

---

## 后端层（API + 业务逻辑 + 多智能体调度）
- **技术**：FastAPI + Python  
- **功能**：
  1. API接口（用户请求、AI调用、资源管理）  
  2. WebSocket / Socket.io 实时推送生成内容  
  3. 用户认证、请求校验  
  4. 多智能体任务调度（调用AI层 + 数据层）  
  5. 流式响应：支持前端边生成边显示

---

## 多智能体调度层
- **技术**：LangGraph + CoordinatorAgent  
- **Agents**：
  - ProfileAgent : 学生画像分析（知识基础、认知风格、易错点等）  
  - PlannerAgent : 学习路径规划、任务分配  
  - ResourceAgent : 生成多模态学习资源（PPT/题库/代码/动画）  
  - CodingAgent : 代码实操案例生成  
  - EvaluationAgent : 学习效果评估与题目自动批改
- **功能**：
  1. 任务拆分、调度、执行  
  2. 协作AI输出，生成最终资源  
  3. 异步任务队列（Redis / Celery）支持高并发

---

## AI层（大模型 + RAG + 工具调用）
- **核心大模型**：科大讯飞星火  
- **框架**：LangChain + Prompt工程 + Tool Calling  
- **向量检索 / RAG**：
  - Chroma / FAISS / Milvus  
  - 功能：快速检索课程文档、题库、PPT、代码案例  
- **功能**：
  1. 多模态资源生成（文本、PPT、视频、动画、代码）  
  2. 智能问答与答疑  
  3. 根据学生画像和学习路径提供个性化输出  
  4. 流式生成，边生成边返回给前端

---

## 数据层（存储 + 缓存 + 向量数据库）
### 1️⃣ 关系型数据库
- **MySQL**  
- 功能：用户信息、学生画像、学习路径、行为日志

### 2️⃣ 缓存 / 队列
- **Redis**  
- 功能：热数据缓存、任务状态、实时推送

### 3️⃣ 对象存储
- **MinIO / S3**  
- 功能：存储多模态资源（PPT / 视频 / 动画 / 代码 / 文档）  
- 版本控制 + CDN加速

### 4️⃣ 向量数据库
- **Chroma / Milvus / FAISS**  
- 功能：RAG检索，支持知识增强与快速问答

---

## 部署层（容器化 + 网络 + 健康检查）
- **核心**：Docker + Docker Compose  
- **网关**：Nginx（统一入口，前后端分离，负载均衡）  
- **数据持久化**：Volumes（MySQL / Redis / MinIO 数据卷）  
- **环境变量管理**：.env 文件统一管理配置  
- **健康检查 & 日志**：容器健康检查 + 日志目录管理  
- **一键启动**：
  - `docker compose up -d`  
  - `start.sh / stop.sh / restart.sh`  
- **可选加分**：
  - CI/CD自动部署  
  - 监控面板 / 流量统计

---

### 💡 总结说明
1. 前端层拆成 UI、聊天/AI交互、多模态可视化、状态管理、工具链，对应详细技术栈。  
2. 后端层用 FastAPI 管理 API 和任务调度，同时和 AI 层协作。  
3. 多智能体层明确每个 Agent 的职责（画像、规划、资源生成、代码、评测）。  
4. AI层重点是 大模型 + RAG检索 + Tool调用 + 流式生成 + 多模态输出。  
5. 数据层清楚区分 结构化数据 / 缓存 / 向量数据库 / 对象存储，保证性能和资源管理。  
6. 部署层用 Docker Compose + Nginx + 持久化 + 健康检查 + 环境管理 + 一键启动，可选CI/CD加分。
