## 文档格式规范

所有知识文档遵循统一的五段式结构：
1. **概念定义** — 清晰定义主题及其核心术语
2. **核心原理** — 深入讲解原理、公式推导、算法流程
3. **示例说明** — 提供具体案例或应用场景
4. **常见误区** — 列出典型误解及正确理解
5. **关键要点** — 总结 3-5 个核心 takeaway

数学公式使用 LaTeX（`$$` 或 `$`），代码示例使用 Markdown 代码块（`` ```python ``）。

## RAG 索引命令

```bash
# 在项目根目录执行
python backend/rag/knowledge_loader.py
```

该命令会遍历 `data/knowledge/` 下所有 `.md` 和 `.json` 文件，按 `##`/`###` 分块后向量化存入 ChromaDB。
