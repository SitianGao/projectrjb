# PPO（Proximal Policy Optimization，近端策略优化）

## 1. 概述

PPO 是目前最广泛使用的强化学习算法之一，由 OpenAI 于 2017 年提出。它解决了策略梯度方法中步长难以控制的核心问题。

### 问题背景

传统策略梯度的问题：
- 步长太大 → 策略崩溃（性能急剧下降）
- 步长太小 → 收敛缓慢
- 需要手动调整学习率，极度敏感

TRPO（Trust Region Policy Optimization）通过约束新旧策略的 KL 散度来解决此问题，但实现复杂。

PPO 用**更简单的方式**实现了类似 TRPO 的效果。

## 2. PPO 的核心机制

### 2.1 重要性采样比率

定义概率比率 r_t(θ)：
```
r_t(θ) = π_θ(a_t|s_t) / π_θ_old(a_t|s_t)
```

- r_t > 1：新策略更倾向于选择该动作
- r_t < 1：新策略减少了该动作的选择概率

### 2.2 Clipping 机制（PPO-Clip）

PPO 的核心创新：对目标函数使用裁剪（clipping）。

```
L_CLIP(θ) = E[min(r_t(θ) * A_t, clip(r_t(θ), 1-ε, 1+ε) * A_t)]
```

其中：
- ε 是裁剪范围（通常 ε = 0.2）
- A_t 是优势函数估计

**工作原理**：
- 当 A_t > 0（好的动作）：r_t 被限制在 1+ε 以下
- 当 A_t < 0（坏的动作）：r_t 被限制在 1-ε 以上
- 防止策略更新过大

### 2.3 自适应 KL 惩罚（PPO-Penalty）

另一种形式，使用 KL 散度惩罚项：
```
L_KLPEN(θ) = E[r_t(θ) * A_t - β * KL(π_θ_old || π_θ)]
```

其中 β 根据 KL 散度自动调整。

## 3. PPO 算法流程

```
1. 初始化策略网络 π_θ 和价值网络 V_φ
2. 重复：
   a. 用当前策略收集 N 步经验 (s_t, a_t, r_t, s_{t+1})
   b. 计算优势函数 A_t（通常使用 GAE）
   c. 多轮优化（K 个 epoch）：
      - 计算 L_CLIP(θ) 损失
      - 使用小批量数据更新策略网络
   d. 更新价值网络：最小化 TD 误差
   e. 同步 θ_old ← θ
```

## 4. GAE（Generalized Advantage Estimation，广义优势估计）

GAE 是常用的优势函数估计方法，平衡偏差和方差：

```
A_t^GAE(λ) = Σ (γλ)^l * δ_{t+l}
```

其中 δ_t = r_t + γ * V(s_{t+1}) - V(s_t)

- λ = 0：等价于 TD(0)，低方差高偏差
- λ = 1：等价于 Monte Carlo，无偏差高方差
- 通常 λ = 0.95

## 5. 实践要点

### 推荐的超参数
- 裁剪范围 ε：0.2
- GAE λ：0.95
- 折扣因子 γ：0.99
- 每轮优化 epoch 数：3-10
- 每轮经验步数：2048-4096
- 学习率：3e-4（Adam）

### 常见调参技巧
- **策略熵正则化**：在损失中加入熵惩罚，鼓励探索
- **价值函数裁剪**：也对价值函数使用裁剪
- **标准化优势**：对优势函数做零均值单位方差归一化
- **观测标准化**：对输入状态做 Running Mean Std 归一化

### PPO 的优势
- 实现简单（相比 TRPO）
- 训练稳定
- 样本效率高
- 在 Atari、MuJoCo 等基准上表现优异
- OpenAI Five（Dota 2）和 ChatGPT RLHF 都使用了 PPO
