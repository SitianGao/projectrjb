# AI 搜索求解策略

## 1. 概念定义

搜索是人工智能中求解问题的基本方法之一。许多 AI 问题（如路径规划、博弈、约束满足）都可以形式化为状态空间中的搜索问题。

**状态空间五要素**：
- **初始状态**：问题的起点
- **目标状态**：问题的终点
- **动作**：从一个状态转移到另一个状态的操作
- **状态转移函数**：描述动作如何改变状态
- **路径代价**：执行动作序列的总代价

---

## 2. 盲目搜索（Uninformed / Blind Search）

盲目搜索不使用问题领域知识，仅根据图的结构进行搜索。

### 2.1 广度优先搜索（BFS）
- 逐层扩展：先扩展完同一层所有节点，再进入下一层
- **完备性**：如果解存在，BFS 一定能找到
- **最优性**：如果每步代价相同，BFS 能找到最短路径
- **空间复杂度**：O(b^d)，b 为分支因子，d 为深度——这是 BFS 的最大瓶颈
- **双向搜索**：同时从起点和终点向中间搜索，可将搜索节点数从 O(b^d) 降至 O(b^(d/2))

### 2.2 深度优先搜索（DFS）
- 沿一条路径深入，到达叶节点后回溯
- **空间复杂度**：O(bd)，远优于 BFS
- **缺点**：不保证最优解，在无限深度空间中可能不终止
- **变体**：迭代加深搜索（IDDFS）兼具 DFS 的空间效率和 BFS 的最优性

---

## 3. 启发式搜索（Informed Search）

启发式搜索利用问题特定知识（启发函数）引导搜索方向，显著提高效率。

### 3.1 启发函数 h(n)
- 估计从节点 n 到目标状态的代价
- **可纳性（Admissible）**：h(n) <= h*(n)，即不高估实际代价——保证 A* 找到最优解
- **一致性（Consistent）**：h(n) <= c(n, a, n') + h(n')——保证不会重复扩展节点
- 常见启发函数：曼哈顿距离（网格地图）、欧几里得距离、错位数（8数码问题）

### 3.2 A* 搜索算法

A* 是最经典的启发式搜索算法，估价函数定义为：

```
f(n) = g(n) + h(n)
```

- g(n)：从初始状态到节点 n 的实际代价（已知）
- h(n)：从节点 n 到目标状态的估计代价（启发函数）

**算法步骤**：
1. 将起始节点放入 Open 表（优先队列，按 f(n) 排序）
2. 若 Open 表为空，则问题无解，搜索结束
3. 取出 Open 表中 f(n) 最小的节点 n，移入 Closed 表
4. 若 n 是目标节点，通过父节点指针回溯得到解路径，结束
5. 扩展 n 的所有后继节点：计算每个后继的 f 值，加入 Open 表
6. 返回步骤 2

**A* 的核心性质**：
- 使用可纳启发函数时，A* 保证找到最优解
- A* 是最优效率的——在可纳启发函数中，没有其他算法能保证扩展更少的节点

### 3.3 其他启发式搜索算法

| 算法 | 估价函数 | 是否保证最优解 |
|------|----------|---------------|
| 贪心搜索 | f(n) = h(n)，仅考虑估计代价 | 否 |
| 爬山法 | 仅向更优方向移动，无回溯 | 否（容易陷入局部最优） |
| 模拟退火 | 概率接受更差解，逃离局部最优 | 否 |
| IDA* | f(n) = g(n) + h(n)，迭代加深 | 是（使用可纳启发时） |
| 束搜索 | 每层仅保留 k 个最优节点 | 否 |

## 4. 遗传算法

遗传算法是一种受生物进化启发的随机优化搜索方法，不依赖梯度信息，适合求解不连续、不可微的复杂优化问题。

**基本要素**：
1. **编码**：将问题的解表示为染色体（如二进制串、实数编码、排列编码）
2. **初始种群**：随机生成一组候选解
3. **适应度函数**：评价每个个体的优劣，通常为目标函数或其适当变换
4. **遗传操作**：
   - **选择（Selection）**：按适应度比例选择父代个体（如轮盘赌选择、锦标赛选择）
   - **交叉（Crossover）**：两个父代交换基因片段生成子代
   - **变异（Mutation）**：随机改变个体的某些基因位，维持种群多样性
5. **终止条件**：达到最大迭代代数或适应度收敛

**改进策略**：
- **精英保留**：直接将最优个体复制到下一代，防止最优解在随机操作中丢失
- **自适应参数**：动态调整交叉率和变异率（前期大范围探索、后期精细局部搜索）

---

## 5. 常见误区

- 误区：A* 算法一定比 BFS 快 → 事实：当启发函数 h(n) = 0 时，A* 完全退化为 BFS；设计不良的启发函数反而可能降低效率
- 误区：遗传算法一定能找到全局最优 → 事实：遗传算法是概率型算法，可能收敛到局部最优解
- 误区：启发函数值越大越好 → 事实：高估实际代价会破坏可纳性，导致 A* 找不到最优解
- 误区：DFS 适用于所有搜索问题 → 事实：在无限深度或存在回路的空间中，DFS 可能永远不终止

---

## 6. 关键要点

- BFS 保证最优但空间消耗大；DFS 空间高效但不保证最优；IDDFS 兼顾两者
- A* 搜索的核心公式：f(n) = g(n) + h(n)，启发函数设计决定了搜索效率
- 启发函数必须满足"可纳性"（保证最优）且应尽可能接近真实代价（提高效率）
- 遗传算法适合不连续、不可微的复杂优化，但属于概率算法，不保证全局最优
- 在实际应用中，选择搜索策略需要在最优性、时间和空间复杂度之间权衡
