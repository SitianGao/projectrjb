# 数据预处理：从原始数据到模型就绪

## 为什么预处理至关重要

*垃圾进，垃圾出。* 原始数据很少能干净到直接用于建模。预处理将混乱、不完整、不一致的数据转换为机器学习算法可以有效学习的结构化格式。跳过这一步是生产环境中模型失败的最常见原因。

---

## 1. 数据清洗

### 1.1 缺失值处理

| 方法 | 描述 | 适用场景 |
|--------|-------------|----------|
| **删除** | 删除含有缺失值的行/列 | 缺失率 < 5% 且为 MCAR（完全随机缺失） |
| **均值/中位数/众数填充** | 用集中趋势值填充 | 快速基线方案；中位数对异常值鲁棒 |
| **KNN 填充** | 使用 k 近邻进行填充 | 捕捉局部结构；大数据集代价较高 |
| **多重填充** | 生成多个合理值，汇总结果 | 统计推断的黄金标准；保留不确定性 |
| **前向/后向填充** | 传播最后一个已知值 | 具有时间依赖性的时间序列 |
| **缺失指示器** | 添加二值标志标记缺失 | 当缺失本身具有信息性时（MNAR） |

```python
from sklearn.impute import SimpleImputer, KNNImputer
imp_mean = SimpleImputer(strategy='median')
imp_knn = KNNImputer(n_neighbors=5)
```

### 1.2 异常值检测

**Z-Score 方法：**
$|z| > 3$ 的点是潜在的异常值，其中 $z = \frac{x - \mu}{\sigma}$。假设数据近似正态分布。

**IQR 方法（Tukey's Fences）：**
下界 = $Q1 - 1.5 \times IQR$，上界 = $Q3 + 1.5 \times IQR$。比 Z-score 更鲁棒——无需正态分布假设。

**孤立森林（Isolation Forest）：** 基于树的异常检测。适用于高维数据，能处理聚类结构。

**DBSCAN：** 基于密度的聚类；未被分配到任何簇的点即为异常值。当异常值位于低密度区域时表现出色。

```python
from sklearn.ensemble import IsolationForest
iso = IsolationForest(contamination=0.05)
outliers = iso.fit_predict(X)  # -1 = outlier
```

### 1.3 重复值删除

务必检查完全重复（`df.drop_duplicates()`）和近似重复（文本的模糊匹配）。重复数据会人为抬高训练指标，并且在按训练/测试拆分时可能导致数据泄漏。

### 1.4 噪声处理

- **分箱/平滑：** 用分箱的均值/中位数/边界值替换原始值
- **滤波：** 对信号数据使用移动平均、Savitzky-Golay 或低通滤波器
- **回归：** 拟合局部回归（LOESS）以平滑噪声趋势

## 2. 特征缩放

许多算法（SVM、KNN、PCA、神经网络、基于梯度下降的方法）对特征尺度敏感。基于树的模型（RF、XGBoost）对尺度不敏感。

### 2.1 标准化（Z-score 归一化）

$$x' = \frac{x - \mu}{\sigma}$$

变换后，特征具有 $\mu = 0$，$\sigma = 1$。**适用于：** SVM、PCA、逻辑回归、神经网络。

### 2.2 最小-最大归一化

$$x' = \frac{x - x_{min}}{x_{max} - x_{min}}$$

将值映射到 $[0, 1]$。**适用于：** 图像像素数据、倾向于有界输入的距离类算法、使用 sigmoid/tanh 激活函数的神经网络。

### 2.3 RobustScaler

$$x' = \frac{x - \text{median}}{\text{IQR}}$$

使用中位数和四分位距进行中心化和缩放。**适用于：** 含有大量异常值的数据——受极端值的影响远小于 StandardScaler。

### 2.4 MaxAbsScaler

$$x' = \frac{x}{\max(|x|)}$$

映射到 $[-1, 1]$，保持稀疏性。**适用于：** 稀疏数据（TF-IDF、独热编码），这些数据在中心化后会破坏稀疏性。

### 2.5 幂变换

- **对数变换：** $\log(x + c)$ — 减少右偏度
- **Box-Cox：** 严格要求正数据；寻找使数据最接近正态分布的最优 lambda
- **Yeo-Johnson：** 可处理负值；是 Box-Cox 的推广

```python
from sklearn.preprocessing import StandardScaler, RobustScaler, PowerTransformer
pt = PowerTransformer(method='yeo-johnson')
```

## 3. 类别变量编码

| 方法 | 机制 | 适用场景 |
|--------|-----------|-------------|
| **标签编码** | 整数映射 `[A,B,C] -> [0,1,2]` | 仅限基于树的模型；对名义特征会引入虚假的顺序性 |
| **独热编码** | 每个类别一个二值列 | 线性模型、神经网络；低基数（< 10-15 个类别） |
| **序数编码** | 尊重顺序的整数映射 | 有序类别：`[low, medium, high] -> [0,1,2]` |
| **目标编码** | 用目标均值替换类别 | 高基数特征；存在过拟合风险——务必使用交叉验证 |
| **频率/计数编码** | 用计数或频率替换 | 高基数特征的快速基线方案；不保留与目标变量的关系 |

```python
from sklearn.preprocessing import OneHotEncoder, OrdinalEncoder
import category_encoders as ce
te = ce.TargetEncoder(cols=['city'], smoothing=10)
```

## 4. 文本预处理

### 标准流程
1. **小写化** — 统一大小写
2. **分词** — 切分为词/子词
3. **停用词移除** — 移除常见词（the、is、at），除非任务需要
4. **词干提取 vs 词形还原** — Porter 词干提取器截断后缀；WordNet 词形还原器生成词典形式。词形还原更慢但更准确。
5. **向量化** — 传统 ML 用 TF-IDF；深度学习用 Word2Vec/GloVe/BERT 嵌入

### 中文文本特殊处理
- **分词是必须的：** 中文没有自然的词边界。在进行任何后续处理之前，使用 `jieba` 进行分词。
- jieba 支持精确模式、全模式和搜索引擎模式。

```python
import jieba
tokens = jieba.lcut("机器学习是人工智能的核心")
```

## 5. 图像预处理

- **调整大小与中心裁剪：** 将输入尺寸标准化以适配 CNN（例如 ResNet 的 224x224）
- **归一化：** 将像素值缩放到 $[0, 1]$ 或使用 ImageNet 统计量按通道标准化
- **数据增强：** 随机水平翻转、旋转（$\pm 10^\circ$）、颜色抖动（亮度、对比度、饱和度）、随机擦除/cutout。对于小型图像数据集，这是防止过拟合的关键手段。

```python
from torchvision import transforms
transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
])
```

## 6. 处理不平衡数据

当一个类别占主导地位时，模型会倾向于预测多数类而忽略少数类。

### 过采样
- **SMOTE：** 通过在近邻之间插值生成合成的少数类样本
- **ADASYN：** 自适应 SMOTE——专注于更难学习的少数类样本

### 欠采样
- **随机欠采样：** 随机丢弃多数类样本
- **Tomek Links：** 移除属于少数类样本最近邻的多数类样本
- **NearMiss：** 选择最接近少数类边界的多数类样本

### 算法层面的方法
- **类别权重：** 按类别频率的倒数加权损失函数
- **集成方法：** BalancedBaggingClassifier、EasyEnsemble

```python
from imblearn.over_sampling import SMOTE
from sklearn.utils.class_weight import compute_class_weight
smote = SMOTE(random_state=42)
class_weights = compute_class_weight('balanced', classes=np.unique(y), y=y)
```

## 7. 流程集成

永远不要在整个数据集上拟合预处理步骤——这会导致数据泄漏。使用 `sklearn.pipeline.Pipeline`：

```python
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer

num_pipe = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler())
])
cat_pipe = Pipeline([
    ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
    ('encoder', OneHotEncoder(handle_unknown='ignore'))
])

preprocessor = ColumnTransformer([
    ('num', num_pipe, numeric_cols),
    ('cat', cat_pipe, categorical_cols)
])

pipeline = Pipeline([
    ('preprocess', preprocessor),
    ('classifier', LogisticRegression())
])
```

## 8. 常见陷阱与最佳实践

1. **数据泄漏：** 永远不要在测试数据上拟合缩放器、填充器或编码器。在训练集上 `fit`，在其他所有数据上 `transform`。
2. **忽视领域知识：** 用均值填充在数学上是方便的，但在物理上往往是错误的（例如，对低温症患者用 37°C 的"均值"填充体温）。
3. **对高基数特征使用独热编码：** 会导致特征空间爆炸。改用目标编码或嵌入。
4. **PCA 之前未正确缩放：** PCA 是方差最大化的——未缩放的特征如果有更大的量级，会主导主成分。
5. **忘记验证集：** 务必在预处理之前进行分割。将预处理串联在流程中，使验证数据永远不会泄漏到训练中。
6. **过度增强：** 过于激进的数据增强可能生成不真实的样本，使模型困惑。
7. **未记录变换：** 务必记录预处理参数，以便在生产环境中复现。
