# 特征工程：从原始数据中构建信号

特征工程是将原始数据转化为让机器学习算法更易发现模式的表示形式的过程。在实践中，优秀的特征往往胜过更复杂的模型——在精心构建的特征集上跑逻辑回归，其表现可以超越在原始输入上跑深度神经网络。

---

## 1. 为什么特征工程至关重要

优秀的特征能够：
- **降低模型复杂度：** 线性关系变得无需深度架构即可学习
- **提升泛化能力：** 基于领域知识的特征更不容易捕捉到虚假相关性
- **减少数据需求：** 更强的特征意味着达到相同性能所需的数据更少

Kaggle 上的一句名言：*"更多数据胜过更好算法，但更好特征胜过更多数据。"*

---

## 2. 特征创建

### 2.1 领域知识特征

最强大的特征来源于对问题的理解：
- **金融：** 负债收入比、市盈率、指数平滑异同移动平均线（MACD）
- **医疗：** BMI（$\frac{weight}{height^2}$）、eGFR、APACHE 评分
- **电商：** 购物车放弃率、客户终身价值、最近一次消费-频率-消费金额（RFM）

### 2.2 多项式与交互特征

从已有特征生成非线性组合：

$$x^2, \quad x_1 x_2, \quad x_1^2 x_2$$

2 次交互项能够捕捉乘法关系。3 次交互项很少值得做，因为维度会急剧膨胀。

```python
from sklearn.preprocessing import PolynomialFeatures
poly = PolynomialFeatures(degree=2, interaction_only=False, include_bias=False)
```

**注意：** $n$ 个特征会变成 $\binom{n+d}{d}$ 个特征。100 个特征加上 2 次方，结果是 5151 个特征。之后务必进行特征选择。

### 2.3 比值和组合特征

对现有列进行简单算术运算：
- $x_1 / (x_2 + \epsilon)$ — 比率、密度、效率
- $x_a - x_b$ — 差值或增量
- $\frac{x - \mu_{group}}{\sigma_{group}}$ — 分组归一化特征

### 2.4 分箱 / 离散化

将连续特征转换为类别分箱：
| 方法 | 原理 | 适用场景 |
|--------|-------------|----------|
| **等宽分箱** | 均匀的区间宽度 | 简单；对异常值敏感 |
| **等频分箱（分位数）** | 每个分箱样本数相同 | 鲁棒；各分箱信息量均衡 |
| **基于决策树的分箱** | 优化目标变量分割的分箱 | 预测能力最强；有过拟合风险 |

```python
from sklearn.preprocessing import KBinsDiscretizer
kbins = KBinsDiscretizer(n_bins=5, encode='ordinal', strategy='quantile')
```

### 2.5 日期时间特征提取

原始时间戳蕴含丰富的周期性和类别信号：

| 特征 | 提取方法 | 编码 |
|---------|-----------|----------|
| 星期几 | `dt.dayofweek` | 0–6 |
| 月份 | `dt.month` | 1–12 |
| 季度 | `dt.quarter` | 1–4 |
| 是否为周末 | `dt.dayofweek >= 5` | 0/1 |
| 小时（周期性） | $\sin(2\pi \cdot \frac{hour}{24})$、$\cos(2\pi \cdot \frac{hour}{24})$ | 连续值，保留"23:00 靠近 00:00"的信息 |

**周期性编码**对时间特征至关重要——它可以防止模型将 23 点和 0 点视为最远的距离。对小时、星期几、月份和风向等特征都应当使用此方法。

```python
df['hour_sin'] = np.sin(2 * np.pi * df['hour'] / 24)
df['hour_cos'] = np.cos(2 * np.pi * df['hour'] / 24)
```

### 2.6 文本特征（在嵌入之外）

在向量化之前或与之并行的简单聚合类文本特征：
- 字符数、词数、句子数
- 平均词长、标点比例、大写比例
- 可读性评分（Flesch-Kincaid、Gunning Fog）
- 情感评分（VADER、TextBlob）
- 命名实体计数（人物、组织、地点）

### 2.7 地理特征

- **Haversine 距离：** 两对经纬度之间的大圆距离
- **Geohash：** 层次化空间编码；相邻地点共享前缀
- **到最近地标的距离：** 机场、市中心、医院

## 3. 特征选择

### 3.1 过滤方法（快速、单变量）

独立评估每个特征与目标变量的关系：

| 方法 | 用于 | 统计量 |
|--------|-----|-----------|
| **方差阈值** | 所有 | 移除方差低于阈值的特征 |
| **皮尔逊相关系数** | 回归 | $r = \frac{\text{cov}(X, y)}{\sigma_X \sigma_y}$ |
| **互信息** | 两者皆可 | $I(X; y)$ — 捕捉非线性依赖 |
| **卡方检验** | 分类 | $\chi^2$ 独立性检验 |
| **ANOVA F 检验** | 分类 | $F = \frac{\text{between-group variance}}{\text{within-group variance}}$ |

```python
from sklearn.feature_selection import SelectKBest, mutual_info_classif, f_classif
selector = SelectKBest(score_func=mutual_info_classif, k=20)
```

### 3.2 包装方法（贪心搜索）

| 方法 | 方法 | 代价 |
|--------|----------|------|
| **RFE（递归特征消除）** | 训练模型，删除最不重要的特征，重复 | 中等；依赖于模型 |
| **前向选择** | 从空集开始，每次添加最佳特征 | $O(kp)$ 次模型训练 |
| **后向消除** | 从全部特征开始，每次移除最差的 | p 很大时代价高昂 |

```python
from sklearn.feature_selection import RFE
from sklearn.ensemble import RandomForestClassifier
rfe = RFE(RandomForestClassifier(), n_features_to_select=30)
```

### 3.3 嵌入方法（在训练过程中）

| 方法 | 选择方式 | 备注 |
|--------|---------------|-------|
| **Lasso (L1)** | 将系数压至精确为零 | 内置特征选择；$\lambda$ 控制稀疏性 |
| **Ridge (L2)** | 收缩系数但保留全部 | 当所有特征都有贡献时效果好 |
| **ElasticNet** | L1 与 L2 的混合 | 兼得两者之长 |
| **树的特征重要性** | 所有分裂中平均不纯度下降 | 快速；偏向于高基数特征 |
| **排列重要性** | 随机打乱特征后模型性能的下降 | 与模型无关；比基于不纯度的重要性更可靠 |

**强烈推荐使用排列重要性**代替基于树的模型内置的特征重要性——它衡量的是实际的预测贡献，而非分裂频率。

```python
from sklearn.inspection import permutation_importance
result = permutation_importance(model, X_val, y_val, n_repeats=10, random_state=42)
```

### 3.4 高级选择方法

**Boruta：** 在随机打乱的特征副本（影子特征）上训练，只保留那些优于其随机对应物的特征。比 RFE 更保守——保留所有相关特征，包括冗余特征。

**稳定性选择：** 在随机子采样上多次运行 Lasso；保留被高频选中的特征。对扰动鲁棒，并能提供假阳性控制。

## 4. 特征变换

| 方法 | 适用场景 | 效果 |
|--------|-------------|--------|
| **对数 $\log(x + c)$** | 右偏、正数据 | 拉近长尾 |
| **平方根 $\sqrt{x}$** | 计数数据 | 稳定方差（泊松） |
| **Box-Cox** | 正数据 | 通过 MLE 优化正态性 |
| **分位数变换** | 任意连续数据 | 映射到均匀或正态分布；完全基于秩 |
| **离散化** | 非线性关系 | 使线性模型学习到分段模式 |

一个常见做法：在线性模型之前，尝试用 `QuantileTransformer(output_distribution='normal')` 作为预处理步骤——对于偏态特征，它通常优于 StandardScaler。

## 5. 降维

### 5.1 PCA（主成分分析）

寻找最大方差的正交方向。线性、快速、可解释（载荷显示了哪些特征对各主成分有贡献）。

```python
from sklearn.decomposition import PCA
pca = PCA(n_components=0.95)  # retain 95% of variance
```

**适用于：** 聚类之前的预处理、加速模型训练、消除多重共线性。**请务必先对数据做缩放。**

### 5.2 核 PCA

PCA 通过核技巧的非线性扩展。当数据位于非线性流形上时非常有用。完全分解的计算代价为 $O(n^3)$。

### 5.3 TruncatedSVD

等价于 PCA，但可以在不进行稠密化的情况下处理稀疏矩阵。对 TF-IDF 或独热矩阵的降维至关重要。

```python
from sklearn.decomposition import TruncatedSVD
svd = TruncatedSVD(n_components=100)
```

### 5.4 t-SNE 与 UMAP（可视化）

**t-SNE：** 出色地保留局部结构。不适合作为下游模型的预处理——其嵌入是非参数化的，无法泛化到新数据点。

**UMAP：** 比 t-SNE 保留更多全局结构。更快，扩展性更好。也主要是一种可视化工具，尽管其参数化变体（parametric UMAP）可以学习映射。

### 5.5 自编码器

通过一个瓶颈层训练神经网络重构其输入。瓶颈层提供了一种可学习的非线性降维。当 PCA 无法捕捉数据流形时非常有用。

## 6. 处理高基数类别特征

当一个类别特征有数百或数千个唯一值时（邮政编码、产品 ID、用户 ID）：

| 方法 | 原理 | 优缺点 |
|--------|-------------|-----------|
| **目标编码** | 用平滑后的目标均值替换 | 功能强大但容易过拟合；需使用交叉验证 |
| **计数编码** | 用频率排名替换 | 无目标泄漏；信息丢失 |
| **实体嵌入** | 通过神经网络为每个类别学习稠密向量 | 最先进的方法；需要深度学习 |
| **CatBoost 编码** | 排序目标编码 | 减少过拟合；CatBoost 的默认方式 |

## 7. 特征交互检测

构建模型后，分析哪些特征之间存在交互：

- **Friedman's H 统计量：** 衡量特征之间的交互强度。计算代价高（$O(n^2)$ 对）。
- **SHAP 交互值：** 将预测分解为主效应和成对交互效应。对于树模型是模型无关的。

```python
import shap
explainer = shap.TreeExplainer(model)
shap_interaction = explainer.shap_interaction_values(X)
```

## 9. 流程集成

特征工程必须放在流程内部以防止泄漏：

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import FunctionTransformer

def create_features(df):
    df = df.copy()
    df['ratio'] = df['a'] / (df['b'] + 1e-6)
    df['day_sin'] = np.sin(2 * np.pi * df['day'] / 7)
    return df

fe_pipe = Pipeline([
    ('features', FunctionTransformer(create_features, validate=False)),
    ('scaler', StandardScaler()),
    ('selector', SelectFromModel(LassoCV())),
    ('model', LogisticRegression())
])
```

## 10. 常见错误与最佳实践

1. **特征创建中的数据泄漏：** 在拆分之前对整个数据集计算组均值或目标编码会泄漏目标信息。务必仅在训练集上拟合特征工程。
2. **特征过多：** 不加选择地添加特征会导致维度灾难、过拟合和训练缓慢。创建后务必进行特征选择。
3. **忽视特征分布：** 对严重偏态的特征不进行变换就直接使用 PCA 或线性模型，会降低结果质量。
4. **独热编码爆炸：** 1000+ 个类别变成 1000+ 个稀疏列。改用目标编码或嵌入。
5. **将周期性特征当作序数特征：** 将月份编码为 1-12 会使一月和十二月距离最远。务必使用正弦/余弦对。
6. **生产环境中的特征漂移：** 基于数据分布（标准化、目标编码）构建的特征必须进行监控——如果分布偏移，特征表示会退化。
7. **过早降维：** 先尝试使用原始特征训练模型。如果性能尚可，牺牲可解释性以换取降维带来的好处并不值得。

## 11. 真实案例研究（Kaggle 风格）

**问题：** 根据上下车坐标、时间戳和乘客数预测出租车费用。

*基线：* 原始特征的线性回归 — RMSE $8.50。

*应用特征工程后：*
1. 上车点和下车点之间的 Haversine 距离（替代原始坐标）
2. 小时（周期性 sin/cos）、星期几、是否为周末
3. 曼哈顿距离作为路线复杂度的代理
4. 到机场的距离（上车点在 JFK/LGA/EWR 2 公里以内）
5. 对费用做对数变换（目标变量右偏）

*结果：* 同一线性回归 — RMSE $3.20，误差 **降低了 62%**，模型本身未做任何改动。这就是特征工程的力量。
