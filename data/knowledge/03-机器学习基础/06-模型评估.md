# 模型评估：衡量真正重要的指标

评估决定了你的模型是否足够好以部署上线。正确的指标取决于具体问题——仅有准确率通常是不够的，有时甚至会严重误导。

---

## 1. 训练集 / 验证集 / 测试集划分

| 数据划分 | 用途 | 典型比例 |
|-------|---------|---------------|
| **训练集** | 拟合模型参数 | 70-80% |
| **验证集** | 调整超参数、检测过拟合、选择模型 | 10-15% |
| **测试集** | 对泛化误差的最终无偏估计 | 10-15% |

**关键原则：** 测试集只能使用一次，放在最后。反复查看测试性能会泄漏信息，使得估计失效。

对于小数据集（< 1000 个样本），优先使用交叉验证而非固定的留出集。

---

## 2. 交叉验证

| 方法 | 描述 | 适用场景 |
|--------|-------------|----------|
| **K 折** | 分为 K 折；在 K-1 折上训练，在留出的折上验证。重复 K 次。 | 通用；K=5 或 10 |
| **分层 K 折** | 保持每折中的类别分布 | 不平衡分类——**始终优先于普通 K 折** |
| **留一法 (LOO)** | K = N；每个样本充当一次验证集 | 极小型数据集；方差高，代价大 |
| **时间序列划分** | 滚动起点，前向链接；绝不使用过去验证未来 | 时间序列预测 |

```python
from sklearn.model_selection import StratifiedKFold, TimeSeriesSplit
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
tscv = TimeSeriesSplit(n_splits=5)
```

## 3. 分类指标

### 3.1 混淆矩阵

所有分类指标的基础：

|  | 预测为正类 | 预测为负类 |
|--|-------------------|-------------------|
| **实际为正类** | TP（真正例） | FN（假负例） |
| **实际为负类** | FP（假正例） | TN（真负例） |

### 3.2 核心指标

**准确率：**
$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$

简单但**对不平衡数据集有误导性。** 对于 99% 都是健康人的群体，一个预测"无疾病"的模型可以达到 99% 的准确率，却毫无用处。

**精确率（正类预测值）：**
$$\text{Precision} = \frac{TP}{TP + FP}$$

"当我预测为正类时，有几次是对的？" **当 FP 代价高昂时使用**——垃圾邮件检测、推荐系统（不相关的推荐会损害用户信任）。

**召回率（灵敏度，真正例率）：**
$$\text{Recall} = \frac{TP}{TP + FN}$$

"我捕获了多少个真正的正类？" **当 FN 代价高昂时使用**——癌症筛查、欺诈检测，漏掉一个案例都是灾难性的。

**特异度（真负例率）：**
$$\text{Specificity} = \frac{TN}{TN + FP}$$

"我正确排除了多少个实际的负类？" 与召回率配合使用，形成完整的评估图景。

### 3.3 综合指标

**F1 分数（精确率与召回率的调和平均数）：**
$$F_1 = 2 \times \frac{P \times R}{P + R}$$

平衡精确率与召回率。调和平均数比算术平均数更严厉地惩罚极端值——你无法通过 P=1.0 且 R=0.0 来糊弄 F1。

**F-beta 分数：** 用 beta 参数推广 F1。$F_\beta = (1 + \beta^2) \times \frac{P \times R}{(\beta^2 \times P) + R}$。$\beta > 1$ 更重视召回率（医疗）；$\beta < 1$ 更重视精确率（垃圾邮件）。

### 3.4 ROC 曲线与 AUC

ROC 曲线在各个分类阈值下绘制 **TPR（召回率）** 对 **FPR（1 - 特异度）** 的关系。

- AUC = 1.0：完美分类器
- AUC > 0.9：优秀
- AUC 0.7–0.8：可接受
- AUC < 0.7：较差
- AUC = 0.5：随机猜测

**何时选择 PR 曲线而非 ROC：** 对于高度不平衡的数据，ROC-AUC 可能会给出误导性的乐观估计。精确率-召回率曲线聚焦于少数类，呈现更真实的评估图景。

**Log Loss（交叉熵）：**
$$-\frac{1}{N}\sum_{i=1}^{N} [y_i \log(\hat{p}_i) + (1 - y_i) \log(1 - \hat{p}_i)]$$

衡量预测 *概率* 的质量，而不仅仅是硬标签。对自信的错误预测给予严厉惩罚。当需要校准后的概率时使用（风险评估、竞价）。

### 3.5 高级指标

**Matthews 相关系数（MCC）：**
$$\text{MCC} = \frac{TP \times TN - FP \times FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$

这是唯一一个只有在模型在混淆矩阵的 *所有四个* 类别上都表现良好时才给予高分的指标。取值范围从 -1 到 +1。通常是不平衡二分类问题的最佳阈值指标。

**Cohen's Kappa：**
$$\kappa = \frac{p_o - p_e}{1 - p_e}$$

衡量纠正了偶然一致性的分类一致性。$p_o$ = 观察到的一致性，$p_e$ = 随机情况下的期望一致性。

## 4. 回归指标

| 指标 | 公式 | 特性 |
|--------|---------|------------|
| **MSE** | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | 平方误差；严厉惩罚大误差；可微分 |
| **RMSE** | $\sqrt{\text{MSE}}$ | 与目标变量单位相同；可解释 |
| **MAE** | $\frac{1}{n}\sum\|y_i - \hat{y}_i\|$ | 线性惩罚；对异常值鲁棒；在零点不可微分 |
| **R²** | $1 - \frac{SS_{res}}{SS_{tot}}$ | 解释的方差比例；比常数均值更差的模型可能为负值 |
| **MAPE** | $\frac{100\%}{n}\sum\|\frac{y_i - \hat{y}_i}{y_i}\|$ | 百分比误差，对业务方直观；当 $y_i = 0$ 时无定义，对小值有偏 |
| **可解释方差** | $1 - \frac{\text{Var}(y - \hat{y})}{\text{Var}(y)}$ | 与 R² 类似但不惩罚偏差 |

**选择指南：** 当异常值是真实且有意义的，使用 MAE。当大错误带来的后果不成比例地更严重时（安全关键场景），使用 MSE/RMSE。用于向利益相关者汇报时，使用 MAPE。

## 5. 聚类指标

### 内部指标（无真实标签）

| 指标 | 公式 | 解释 |
|--------|---------|---------------|
| **轮廓系数** | $\frac{b-a}{\max(a,b)}$ | $a$ = 簇内平均距离，$b$ = 到最近簇的距离。取值范围 $[-1, 1]$；越高越好。 |
| **Davies-Bouldin 指数** | 各簇与其最相似簇之间的平均相似度 | 越低越好；惩罚重叠簇 |
| **Calinski-Harabasz** | 簇间离散度与簇内离散度的比值 | 越高越好；假设簇为球形 |

### 外部指标（有真实标签）

- **调整 Rand 指数（ARI）：** 基于样本对计数的度量，对随机情况进行校正。取值范围 $[-1, 1]$。
- **归一化互信息（NMI）：** 基于信息论的指标；衡量真实标签与预测标签之间共享的信息量。

## 6. 过拟合检测与学习曲线

**过拟合的特征：** 训练损失持续下降，而验证损失开始上升。二者之间的差距不断扩大。

**欠拟合的特征：** 训练和验证损失都居高不下；模型尚未学到数据背后的模式。

**学习曲线**绘制性能与训练集大小的关系：
- **高偏差：** 两条曲线都在较低的分数趋于平稳，曲线之间的差距很小。解决方案：更复杂的模型、更多特征。
- **高方差：** 训练曲线和验证曲线之间存在巨大差距。解决方案：更多数据、正则化、更简单的模型。

---

## 7. 误差分析

在汇总指标之外，深入挖掘模型犯了 *哪些* 错误：

1. **逐类别分解：** 计算每个类别的精确率/召回率。是否有某些类别被系统性错误分类？
2. **置信度校准：** 绘制预测概率与实际频率的关系图（可靠性图）。
3. **最差样本分析：** 检查最高损失的样本。往往会出现规律——特定数据来源、边缘情况、标注噪声。
4. **基于切片评估：** 在有意义的子群体上进行评估（例如按地理位置、设备类型、人口统计特征）。

## 8. 模型比较的统计检验

### McNemar 检验
通过计数不同预测的样本，在同一测试集上比较两个分类器。$H_0$：两个分类器具有相同的错误率。

### 配对 t 检验（5x2cv）
运行 5 次迭代的 2 折交叉验证；用配对 t 检验比较得分差异。

### Wilcoxon 符号秩检验
配对 t 检验的非参数替代方法。当得分差值不服从正态分布时使用。

### 已部署模型的 A/B 测试
- 通过功效分析确定样本量（最小可检测效应，显著性水平 $\alpha = 0.05$，功效 $= 0.80$）
- 随机将用户分配到模型 A（对照）和模型 B（处理）
- 跟踪业务指标（转化率、点击率），而不仅仅是 ML 指标
- 区分 **统计显著性**（$p < 0.05$）与 **实际显著性**（效应足够大，值得做出改变）

