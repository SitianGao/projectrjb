# 编程题：两数之和

## 题目描述
给定一个整数数组 nums 和一个整数目标值 target，请你在数组中找出和为 target 的两个整数的索引（从 0 开始）。你可以假设每种输入只会对应一个答案。

## 输入格式
第一行：整数 n 和 target（空格分隔）
第二行：n 个整数（空格分隔）

## 输出格式
两个索引值（空格分隔），较小的索引在前

## 输入样例
```
4 9
2 7 11 15
```

## 输出样例
```
0 1
```

## 测试用例
```json
[
  {"input": "4 9\n2 7 11 15", "output": "0 1"},
  {"input": "3 6\n3 2 4", "output": "1 2"},
  {"input": "2 6\n3 3", "output": "0 1"},
  {"input": "5 10\n1 3 5 7 9", "output": "0 3"},
  {"input": "6 20\n10 15 3 7 2 10", "output": "0 1"}
]
```
