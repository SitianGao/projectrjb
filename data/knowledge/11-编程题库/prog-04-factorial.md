# 编程题：阶乘计算

## 题目描述
计算非负整数 n 的阶乘 n! = 1 x 2 x 3 x ... x n。规定 0! = 1。需使用循环或递归实现。

## 输入格式
一个整数 n（0 <= n <= 20）

## 输出格式
n 的阶乘值

## 输入样例
```
5
```

## 输出样例
```
120
```
