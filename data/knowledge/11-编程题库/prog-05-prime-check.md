# 编程题：素数判定

## 题目描述
判断给定的整数 n 是否为素数（质数）。素数定义为大于 1 的自然数中，除了 1 和它本身以外不再有其他因数的数。

## 输入格式
一个整数 n（1 <= n <= 10^9）

## 输出格式
若 n 是素数，输出 "YES"；否则输出 "NO"

## 输入样例
```
17
```

## 输出样例
```
YES
```

## 测试用例
```json
[
  {"input": "17", "output": "YES"},
  {"input": "1", "output": "NO"},
  {"input": "2", "output": "YES"},
  {"input": "4", "output": "NO"},
  {"input": "97", "output": "YES"},
  {"input": "1000000007", "output": "YES"},
  {"input": "999999937", "output": "YES"}
]
```
