# 编程题：斐波那契数列

## 题目描述
斐波那契数列定义为：F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2)。请计算第 n 项的值。

## 输入格式
一个整数 n（0 <= n <= 45）

## 输出格式
F(n) 的值

## 输入样例
```
10
```

## 输出样例
```
55
```

## 测试用例
```json
[
  {"input": "10", "output": "55"},
  {"input": "0", "output": "0"},
  {"input": "1", "output": "1"},
  {"input": "20", "output": "6765"},
  {"input": "30", "output": "832040"},
  {"input": "45", "output": "1134903170"}
]
```
