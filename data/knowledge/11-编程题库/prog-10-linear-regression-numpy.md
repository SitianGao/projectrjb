# 编程题：梯度下降实现线性回归

## 题目描述
实现批量梯度下降算法来拟合线性回归模型 y = w0 + w1 * x。给定 n 个数据点 (x_i, y_i)，使用均方误差 MSE 作为损失函数，输出训练后的模型参数。

## 输入格式
第一行：n learning_rate epochs（数据点数、学习率、迭代轮数）
接下来 n 行：每行两个浮点数 x_i y_i

## 输出格式
一行：两个浮点数 w0 w1（保留4位小数，空格分隔）

## 输入样例
```
5 0.01 1000
1 2
2 4
3 6
4 8
5 10
```

## 输出样例
```
0.0000 2.0000
```

[
