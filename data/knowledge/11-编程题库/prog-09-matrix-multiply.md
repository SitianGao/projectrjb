# 编程题：矩阵乘法

## 题目描述
给定两个矩阵 A（m x n）和 B（n x p），计算它们的乘积 C = A x B（m x p 矩阵）。

## 输入格式
第一行：m n p（三个整数，空格分隔）
接下来 m 行：矩阵 A 的 m x n 个整数
接下来 n 行：矩阵 B 的 n x p 个整数

## 输出格式
m 行，每行 p 个整数，表示矩阵 C 的各元素（每行内空格分隔）

## 输入样例
```
2 3 2
1 2 3
4 5 6
1 2
3 4
5 6
```

## 输出样例
```
22 28
49 64
```
