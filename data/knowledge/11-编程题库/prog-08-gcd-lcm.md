# 编程题：最大公约数与最小公倍数

## 题目描述
给定两个正整数 a 和 b，计算它们的最大公约数（GCD）和最小公倍数（LCM）。建议使用欧几里得算法（辗转相除法）求解 GCD。

## 输入格式
一行，两个正整数 a 和 b（空格分隔，1 <= a, b <= 10^6）

## 输出格式
一行，GCD 和 LCM（空格分隔）

## 输入样例
```
12 18
```

## 输出样例
```
6 36
```

## 测试用例
```json
[

  {"input": "999999 1000000", "output": "1 999999000000"}
]
```
