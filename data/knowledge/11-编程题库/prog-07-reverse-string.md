# 编程题：字符串反转

## 题目描述
给定一个字符串，将其反转后输出。

## 输入格式
一行字符串（长度 <= 1000，可能包含空格）

## 输出格式
反转后的字符串

## 输入样例
```
hello world
```

## 输出样例
```
dlrow olleh
```

## 测试用例
```json
[
  {"input": "hello world", "output": "dlrow olleh"},
  {"input": "abc", "output": "cba"},
  {"input": "a", "output": "a"},
  {"input": "12345", "output": "54321"},
  {"input": "level", "output": "level"},
  {"input": "Data Structure", "output": "erutcurtS ataD"}
]
```

## 标签
字符串

## 难度
简单

## 建议时间
10 分钟
