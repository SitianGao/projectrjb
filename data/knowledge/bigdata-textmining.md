## 1. 大数据基础

### 1.1 什么是大数据

大数据是指在面对极其庞大且复杂的数据时，无法使用手工分析或传统分析（如抽样调查）时，使用自然语言处理、信息检索、机器学习等技术抽取知识，转化为智慧的方法学。

### 1.2 大数据的四大特征 (4V)

| 特征 | 说明 |
|------|------|
| **Volume（数据量巨大）** | TB、PB 级别 |
| **Variety（数据类型繁多）** | 结构化、半结构化、非结构化 |
| **Value（价值密度低）** | 大量数据中提取少量有价值信息 |
| **Velocity（流动速度快）** | 实时产生、实时处理 |

### 1.3 小数据 vs 大数据

| 维度 | 小数据 | 大数据 |
|------|--------|--------|
| 采集方式 | 样本反馈 | 检测记录 |
| 性质 | 主观的 | 客观的 |
| 关注点 | 结果 | 过程 |
| 结构 | 结构化的 | 非结构化的 |
| 时序 | 离散的 | 连续的 |

### 1.4 大数据应用案例

1. **社交舆情操控** — 基于心理学模型，分析社交网络用户行为
2. **舆情画像分析** — 黑公关检测、舆情时间线、跟帖语义分析、主观舆情分析
3. **文档核查** — 大规模文档自动审核与查重

## 2. 文本挖掘

### 2.1 文本挖掘框架

```
语音库 + 文本库 → 文本特征处理 → 文本数据结构化 → 数据挖掘
```

### 2.2 文本表示模型

#### 布尔检索模型
- 文档由一组标引词描述，权重为 0 或 1
- 采用**倒排索引**匹配
- 优点：速度快
- 缺点：无法按相关性排序

#### 向量空间模型 (VSM)

**TF-IDF 核心公式：**

- **TF (词频)**：$tf_{ij}$ = 词项 $t_j$ 在文档 $D_i$ 中出现的频率
- **IDF (逆文档频率)**：$idf_j = \log(\frac{d}{df_j})$
  - $d$ = 所有文档篇数
  - $df_j$ = 包含词项 $t_j$ 的文档篇数
- **TF-IDF**：$d_{ij} = tf_{ij} \times idf_j$

> 示例：文档总词数100，"母牛"出现3次 → TF=0.03；10000份文档中1000份含"母牛" → IDF=log(10)=1；TF-IDF=0.03

#### 概率检索模型
解决两个基本问题：**参数估计** 和 **独立性假设**。

### 2.3 文本特征选择方法

#### 信息增益 (Information Gain)
二分类下：
$$IG(c,f) = P(c|f)\log(P(c|f)) + P(c|\bar{f})\log(P(c|\bar{f}))$$

#### 交叉熵 (Cross Entropy)
$$CE(c,f) = P(c|f)\log(P(c|f))$$

### 2.4 KL 散度（相对熵）

$$D(P||Q) = \sum_{x \in X} P(x)[\log(P(x)) - \log(Q(x))]$$

用于描述两个概率分布之间的差异。经典应用：《红楼梦》前后作者同一性分析。
