# 自然语言处理概述

> 来源：BIT-AI-Review 仓库

## 1. NLP 发展历程

NLP主要算法体系的三个发展阶段：

| 阶段 | 方法 | 代表技术 |
|------|------|----------|
| **理性主义** | 规则方法 | 专家系统、语法规则 |
| **经验主义** | 统计方法 | HMM、CRF、TF-IDF |
| **认知主义** | 神经网络方法 | Word2Vec、LSTM、BERT、GPT |

## 2. 深度学习对NLP的重要推动

### 2.1 词嵌入 (Word Embedding)

将原有**高维、离散、稀疏**的词汇表示映射为**低维、连续、稠密**的分布式表示。

- 有效克服传统方法的**维数灾难**问题
- 语义相近的词在向量空间中距离更近
- 经典模型：Word2Vec、GloVe、FastText

### 2.2 深度学习模型演进

```
CNN → RNN → LSTM → GRU → Attention → Transformer → BERT → GPT
```

| 模型 | 核心创新 | 局限 |
|------|----------|------|
| **CNN** | 局部特征提取、并行计算 | 无法捕捉长距离依赖 |
| **RNN** | 序列建模、隐藏状态传递 | 梯度消失/爆炸 |
| **LSTM** | 门控机制（遗忘门、输入门、输出门） | 计算复杂、无法并行 |
| **GRU** | 简化门控（更新门、重置门） | 表达能力略弱于LSTM |
| **Attention** | 动态关注输入的不同部分 | 计算量大 |
| **Transformer** | 全注意力机制、并行训练 | 位置编码需求 |
| **BERT** | 双向编码、掩码语言模型 | 仅编码，不生成 |
| **GPT** | 单向解码、自回归生成 | 单向注意力限制 |

## 3. 核心NLP任务

### 3.1 基础任务
- **分词** — 将文本切分为词或子词单元
- **词性标注** — 标注每个词的词性
- **命名实体识别 (NER)** — 识别人名、地名、机构名等
- **句法分析** — 分析句子语法结构

### 3.2 进阶任务
- **文本分类** — 情感分析、主题分类、垃圾邮件检测
- **信息抽取** — 关系抽取、事件抽取、知识图谱构建
- **机器翻译** — 源语言到目标语言的自动翻译
- **问答系统** — 根据问题从文本中找答案
- **文本摘要** — 自动生成文本的核心摘要
- **对话系统** — 多轮对话、意图理解、对话生成

### 3.3 前沿方向
- **大语言模型 (LLM)** — GPT-4、Claude、文心一言等
- **多模态学习** — 文本+图像+语音的联合理解
- **提示工程 (Prompt Engineering)** — 通过精心设计的提示引导模型输出
- **RAG (检索增强生成)** — 结合外部知识库提升生成质量

## 4. 文本表示方法对比

| 方法 | 维度 | 稀疏性 | 语义信息 |
|------|------|--------|----------|
| One-Hot | 词表大小 | 极度稀疏 | 无 |
| TF-IDF | 词表大小 | 稀疏 | 统计信息 |
| Word2Vec | ~300 | 稠密 | 语义相近词距近 |
| BERT Embedding | ~768 | 稠密 | 上下文感知 |
