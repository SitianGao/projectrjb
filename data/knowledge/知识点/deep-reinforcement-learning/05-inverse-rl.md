# 逆向强化学习（Inverse Reinforcement Learning, IRL）

## 1. 概述

### 正向 vs 逆向强化学习

| 方向 | 问题描述 | 已知 | 目标 |
|------|----------|------|------|
| 正向 RL | 给定奖励 → 学习最优策略 | 奖励函数 R | 策略 π |
| 逆向 RL | 观察专家行为 → 推断奖励函数 | 专家演示 D | 奖励函数 R |

### 动机

在许多实际场景中：
- **奖励函数难以设计**（自动驾驶：如何量化"安全驾驶"？）
- **专家演示容易获取**（人类驾驶数据）
- IRL 从演示中学习隐含的奖励函数

## 2. IRL 基本框架

### 问题形式化

给定：
- 专家轨迹集合 D = {τ₁, τ₂, ...}
- 环境动态 P(s'|s, a)

目标：推断奖励函数 R(s) 或 R(s, a)，使得专家策略在此奖励下是最优的。

### 核心挑战：歧义性

IRL 是一个病态问题（ill-posed）：
- 无穷多个奖励函数可以解释相同的行为
- 全零奖励使任何策略都是最优的
- 需要额外的约束或先验

## 3. 主要 IRL 方法

### 3.1 学徒学习（Apprenticeship Learning）

**核心思想**：学习一个策略，使其特征期望匹配专家。

- 假设奖励是特征的线性组合：R(s) = w^T * φ(s)
- 策略的价值 = w^T * μ(π)，其中 μ(π) 是特征期望
- 学习目标：minimize ||μ(π) - μ(π_E)||
- 使用最大边际规划（Maximum Margin Planning）

**算法流程**：
1. 计算专家特征期望 μ_E
2. 迭代：求解当前奖励的最优策略 → 比较特征期望 → 调整权重

### 3.2 最大熵 IRL（Maximum Entropy IRL）

**核心思想**：在满足特征匹配的前提下，最大化策略的熵。

```
P(τ|θ) ∝ exp(Σ R_θ(s_t, a_t))
```

- 奖励函数用神经网络参数化 R_θ
- 训练目标：最大化 log P(D|θ)
- 使用 Ziebart 算法或 Guided Cost Learning

**优势**：
- 处理次优演示
- 概率解释优雅
- 可扩展到大状态空间

### 3.3 GAIL（Generative Adversarial Imitation Learning）

**核心思想**：用 GAN 的框架做 IRL。

**架构**：
- **生成器（Generator）**：策略网络 π_θ（生成行为）
- **判别器（Discriminator）**：D_φ(s, a)（区分专家 vs 生成）

**目标函数**：
```
min_θ max_φ E_{(s,a)~π_E}[log D(s,a)] + E_{(s,a)~π_θ}[log(1 - D(s,a))]
```

**GAIL 的等价性**：GAIL 的最优判别器等价于 IRL 的最优奖励函数。

**算法流程**：
1. 用当前策略 π_θ 采样轨迹
2. 更新判别器 D_φ（区分专家/生成数据）
3. 用 D_φ 的输出来计算"奖励"：r(s,a) = -log(1-D(s,a))
4. 用这些奖励更新策略 π_θ（如 PPO、TRPO）
5. 重复直到判别器无法区分

## 4. IRL 与 RLHF 的关系

### RLHF（Reinforcement Learning from Human Feedback）

- IRL → 从行为演示推断奖励
- RLHF → 从人类偏好（比较）学习奖励
- 本质联系：都在学习隐含的奖励函数
- RLHF 思路：先训练奖励模型预测人类偏好，再用 RL 优化策略

### 在 LLM 中的应用

ChatGPT 的训练流程：
1. SFT（Supervised Fine-Tuning）：用人类生成的回答微调
2. RM（Reward Modeling）：训练奖励模型预测人类偏好
3. PPO：用奖励模型优化语言模型策略

## 5. 实践要点

### 何时使用 IRL
- 奖励函数难以显式定义
- 有高质量专家演示数据
- 希望学习可解释的奖励函数
- 需要泛化到新环境（奖励比策略更容易泛化）

### 数据要求
- 专家演示质量直接影响学习效果
- 并非必须最优演示（最大熵方法可处理次优数据）
- 演示多样性重要

### 常见陷阱
- 特征选择影响 IRL 结果
- 与环境交互成本高（需要正向 RL 内循环）
- 过拟合专家演示（缺乏探索）
