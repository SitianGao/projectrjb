# Reward Shaping（奖励塑形）

## 1. 奖励函数设计问题

### 稀疏奖励（Sparse Reward）

最常见的强化学习挑战：
- 只有完成目标才有奖励（如围棋赢棋 +1，输棋 -1）
- 中间步骤没有反馈
- 智能体难以学习有效的探索策略
- **结果**：随机探索几乎不可能碰到奖励

### 密集奖励（Dense Reward）

手工设计密集奖励的问题：
- 需要大量领域知识
- 可能引入人类偏见
- 智能体可能找到"钻空子"的方式获取奖励
- **奖励 hacking**：智能体优化奖励但偏离真实目标

## 2. Reward Shaping 基础

### 定义

Reward Shaping 是指在原始奖励 R(s, a) 基础上，添加辅助奖励 F(s, a)，形成新的奖励函数：

```
R'(s, a) = R(s, a) + F(s, a)
```

### 势能基础奖励塑形（Potential-Based）

为了不改变最优策略，F 需满足：
```
F(s, a) = γ * Φ(s') - Φ(s)
```

其中 Φ(s) 是状态势能函数（任意实数函数）。

**直观理解**：Φ(s) 给每个状态赋予"势能"，智能体倾向于向势能增加的方向移动。

### 如何选择 Φ(s)
- 距离目标的负距离
- 启发式值函数估计
- 从专家演示中学习

## 3. Curiosity-driven Exploration（好奇心驱动探索）

### 核心思想

智能体应该主动探索**不确定**或**新颖**的状态。

### Intrinsic Curiosity Module (ICM)

```
R'(s, a) = R(s, a) + β * |ŝ' - s'|²
```

- 预测下一个状态 s'（前向动态模型）
- 预测误差大 → 新颖状态 → 高好奇心奖励
- β 控制探索权重

### 随机网络蒸馏（RND）

- 使用两个神经网络：目标网络（固定随机初始化）和预测网络（可训练）
- 预测误差作为探索奖励
- 见过的状态预测误差小，新状态误差大

## 4. Curriculum Learning（课程学习）

### 基本思想

借鉴人类教育理念：从简单到困难逐步学习。

### 实现方法

1. **难度排序**：将任务按难度排序
2. **逐步推进**：当性能达到阈值后切换到更难的任务
3. **自动课程**：根据智能体当前能力动态调整难度

### 应用示例

- 参数化环境（如不同的重力、摩擦系数）
- 目标距离递增
- 对手能力递增

## 5. 层次化强化学习（HRL）

### 核心思想

将复杂任务分解为子任务层次结构：
- **高层策略**：选择子目标
- **低层策略**：执行具体动作达成子目标

### 选项框架（Options Framework）

- Option = (启动条件 I, 内部策略 π, 终止条件 β)
- 高层策略在选项之间切换
- 每个选项封装一个子技能

### 优势
- 时间抽象：高层策略的决策频率低于低层
- 迁移学习：子技能可以在不同任务间共享
- 探索效率：结构化探索

## 6. 实践建议

### 奖励设计原则
- 从简单到复杂：先用密集奖励训练，再逐步稀疏化
- 避免奖励 hacking：定期人工检查智能体行为
- 使用 Reward Shaping 辅助稀疏奖励任务

### 调试技巧
- 记录总奖励（包括 shaping reward）的分解
- 监控好奇心模块的预测误差
- 可视化状态势能函数
