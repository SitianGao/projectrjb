# 人工智能基础概念

> 来源：BIT-AI-Review 仓库

## 1. 什么是人工智能？

麦卡锡在达特茅斯会议上提出AI的定义：**使一部机器的反应方式像一个人在行动时所依据的智能**。

### 1.1 人工智能三个层次

| 层次 | 核心能力 | 技术手段 | 典型应用 |
|------|----------|----------|----------|
| **弱人工智能** | 计算能力 | 人工规则 + AI优化策略 | AlphaGo |
| **强人工智能** | 受限环境下的感知能力 | 物联网、语音识别、计算机视觉 | 自动驾驶 |
| **超人工智能** | 非受限环境下的认知能力 | 自然语言理解、知识推理 | 能听、能互动 |

### 1.2 AI 能做什么 vs 不能做什么

**能做：**
- 不需要同情心的劳动密集型产业
- 可以用数学进行描述的问题
- 模式识别、分类、预测

**不能做：**
- 抽象能力
- 常识推断
- 知其然且知其所以然
- 情感
- 自我意识

## 2. 数据的智能演化过程

数据 → 信息 → 知识 → 智能

| 阶段 | 定义 |
|------|------|
| **数据** | 用于表示客观事物的未经加工的原始素材（如二进制串） |
| **信息** | 用来消除随机不定性的东西（香农定义） |
| **知识** | 信息从量变到质变的产物，蕴含深度规律 |
| **智能** | 知识进一步归纳总结后获得的普适规律，可演化为更多知识 |

## 3. 三个时代的变革

| 时代 | 变革类型 |
|------|----------|
| 计算机时代 | 计算方式的变革 |
| 互联网时代 | 信息传播方式的变革 |
| 大数据时代 | **决策方式的变革** |

大数据时代决策特征：决策主体从供给侧转向需求侧、决策依据从供给能力转向用户需求、决策机制从反馈转向预测、决策效率从期间转向实时。

## 4. AI 专业核心能力

- **数学基础**：线性代数、概率统计、最优化方法、矩阵分析
- **编程能力**：Python、C++、CUDA并行编程
- **核心课程**：机器学习、深度学习、计算机视觉、自然语言处理、强化学习
- **实践能力**：大量实验项目，以实践驱动理论学习
- **前沿跟踪**：论文阅读、开源项目复现、学术讨论

## 5. 经典AI领域

1. **机器学习** — 数据驱动的模型训练与预测
2. **深度学习** — 多层神经网络自动提取特征
3. **计算机视觉** — 图像识别、目标检测、图像生成
4. **自然语言处理** — 文本理解、机器翻译、对话系统
5. **语音识别与合成** — 声学模型、语言模型
6. **强化学习** — 通过奖惩信号学习最优策略
7. **知识工程** — 知识图谱构建与推理
8. **认知科学** — 模拟人类认知过程的计算模型
