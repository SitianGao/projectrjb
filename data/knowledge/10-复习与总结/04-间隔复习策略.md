# 间隔复习策略 —— 基于艾宾浩斯遗忘曲线

## 1. 遗忘曲线原理

艾宾浩斯遗忘曲线描述了人类记忆随时间衰减的规律：

$$R = e^{-t/S}$$

其中：
- $R$：当前记忆保留率（0-1）
- $t$：距上次学习的天数
- $S$：记忆强度参数（受学习深度、理解程度影响）

**关键发现**：
- 首次学习后 20 分钟内遗忘约 42%
- 1 小时后遗忘约 56%
- 1 天后遗忘约 74%
- 1 周后仅保留约 21%

## 2. 间隔复习的最佳时机

### 2.1 触发阈值

当记忆保留率 $R < 0.6$（60%）时，应触发一次复习。

| 保留率区间 | 紧急程度 | 推荐动作 |
|-----------|---------|---------|
| $R < 0.35$ | 🔴 高 | 立即安排完整复习，先重读讲解文档，再做练习题 |
| $0.35 \leq R < 0.50$ | 🟡 中 | 本周内安排复习，侧重练习和错题重做 |
| $0.50 \leq R < 0.60$ | 🟢 低 | 下周内抽时间温习关键概念和公式 |

### 2.2 复习节奏建议

科学复习间隔（从首次学习算起）：
1. **第 1 天**：学完后立即做练习题（主动回忆）
2. **第 3 天**：回顾笔记，重做错题
3. **第 7 天**：做综合练习，串联相关知识点
4. **第 14 天**：自查能否独立复述核心概念
5. **第 30 天**：限时完成一套模拟题

## 3. 针对不同薄弱类型的复习策略

### 3.1 概念理解薄弱 → 推荐 document + mindmap
**表现**：能做题但说不清原理，选择题容易掉进概念陷阱
**策略**：先用思维导图建立知识框架，再精读讲解文档中的定义和推导

### 3.2 计算/推导薄弱 → 推荐 exercise + document
**表现**：概念理解但对公式推导和数学计算感到吃力
**策略**：从简单推导题开始，逐步增加复杂度，配合文档中的公式推导步骤

### 3.3 代码实现薄弱 → 推荐 code + exercise
**表现**：理论清楚但写不出代码，或代码经常有 bug
**策略**：先模仿文档中的示例代码，再做变式练习（改参数、换数据集）

### 3.4 综合应用薄弱 → 推荐 exercise + code + reading
**表现**：单个知识点 OK，但面对综合题目无从下手
**策略**：做跨知识点的综合题，阅读拓展材料打开思路，补写项目代码

## 4. 记忆强度的动态调整

每次学习/复习后，记忆强度参数 $S$ 需要更新：

$$S_{new} = \max(1.0, \ S_{old} \times (0.5 + \text{avg\_score}))$$

- 正确率 100%：$S$ 增大 1.5 倍（记忆更牢固）
- 正确率 50%：$S$ 保持不变
- 正确率 30%：$S$ 缩小到 0.8 倍（记忆脆弱，需更频繁复习）

## 5. 复习效果评估

一次有效的复习应达到：
- 练习正确率 ≥ 80%
- 能在 5 分钟内用自己的话复述核心概念
- 能将知识点与前后相关内容串联（不孤立记忆）

> **注意**：本策略基于经典遗忘曲线理论。个体差异（认知风格、学习环境、睡眠质量）会影响实际遗忘速度，建议结合系统评估结果动态调整复习计划。
