# 人工智能核心知识复习

## 1. 知识表示与推理

### 1.1 知识表示方法
- **一阶谓词逻辑**：用命题、谓词、量词（全称/存在）形式化表达知识，支持逻辑推理
- **产生式系统**：IF-THEN 规则库 + 推理机 + 综合数据库，适合专家系统
- **语义网络**：节点（实体）+ 边（关系），支持 IS-A、Part-Of 等层次关系
- **框架表示法**：框架-槽结构，类似面向对象中的类-属性模型

### 1.2 知识图谱
- 实体-关系-实体三元组（如 <张三, 就读于, 清华大学>）
- 知识抽取：实体识别 → 关系抽取 → 属性抽取
- 知识融合：实体对齐、冲突消解
- 应用：搜索引擎、推荐系统、智能问答

## 2. 搜索求解策略

### 2.1 盲目搜索 vs 启发式搜索
- **BFS**：逐层扩展，保证最优但空间复杂度 O(b^d)
- **DFS**：深度优先，空间效率高 O(bd)，但不保证最优
- **A* 算法**：f(n) = g(n) + h(n)，可纳启发保证最优，是最优效率的搜索算法

### 2.2 启发函数设计要点
- 必须满足可纳性（不高估实际代价）以保证最优解
- 应尽可能接近真实代价以提高搜索效率
- 常见选择：曼哈顿距离（网格）、欧几里得距离、错位数

### 2.3 遗传算法要点
- 编码方案 → 初始种群 → 适应度评估 → 选择/交叉/变异 → 迭代
- 精英保留策略：防止最优解在随机操作中丢失
- 适合不连续、不可微的复杂优化问题

## 3. 贝叶斯网络与概率推理

### 3.1 基础概念
- **先验概率**：在没有任何证据的情况下对事件的信念
- **条件概率**：P(A|B) = P(A,B) / P(B)
- **贝叶斯公式**：P(H|E) = P(E|H) * P(H) / P(E)
- **条件独立性**：给定父节点，节点与其非后代节点条件独立

### 3.2 贝叶斯网络推理
- **精确推理**：变量消元法——逐步求和消除非查询变量
- **近似推理**：马尔可夫链蒙特卡洛（MCMC）方法，适合大规模网络

## 4. 对抗搜索（博弈）

### 4.1 Minimax 算法
- 零和博弈：我方最大化收益 = 对手最小化我方收益
- 递归评估博弈树：MAX 层选最大值，MIN 层选最小值
- 完备性：在有限博弈树中保证找到最优策略

### 4.2 Alpha-Beta 剪枝
- 维护 alpha（MAX 的最佳选择下界）和 beta（MIN 的最佳选择上界）
- 当 alpha >= beta 时剪枝，避免搜索不可能被选择的子树
- 理想情况下可将搜索节点数从 O(b^d) 降至 O(b^(d/2))

---

## 5. 常见误区汇总

- 误区：可纳启发函数一定能高效搜索 → 事实：可纳性仅保证最优，不保证效率（h(n)=0 也可纳但退化为 BFS）
- 误区：贝叶斯网络需要完整概率表 → 事实：条件独立性可以显著减少所需参数数量
- 误区：Alpha-Beta 剪枝改变 Minimax 的结果 → 事实：剪枝仅跳过不可能影响结果的子树，结果与完整 Minimax 一致
- 误区：遗传算法交叉率越高越好 → 事实：过高交叉率会破坏优良个体，过低则搜索效率不足

## 6. 关键概念速查

| 概念 | 一句话总结 |
|------|-----------|
| A* 搜索 | f = g + h，可纳启发保证最优 |
| 贝叶斯公式 | P(H|E) = P(E|H)P(H)/P(E) |
| Minimax | MAX 和 MIN 交替选择，零和博弈最优策略 |
| Alpha-Beta 剪枝 | 维护上下界，跳过不可能的分支 |
| 遗传算法 | 选择-交叉-变异，模拟生物进化 |
| 知识图谱 | 实体-关系-实体，语义网络结构化知识 |
