# 机器学习核心知识复习

## 1. 机器学习概述

### 1.1 什么是机器学习
机器学习是研究如何通过经验（数据）自动改进算法性能的领域。Tom Mitchell 的经典定义：对于某类任务 T 和性能度量 P，如果计算机程序在 T 上以 P 衡量的性能随着经验 E 而自我改善，则称该程序从经验 E 中学习。

### 1.2 三大学习范式
- **监督学习**：数据有标签，学习输入到输出的映射（分类、回归）
- **无监督学习**：数据无标签，发现数据内在结构（聚类、降维）
- **强化学习**：通过与环境交互、根据奖励信号学习最优策略

### 1.3 泛化能力
模型在训练集之外的新样本上的表现能力。过拟合（低偏差、高方差）和欠拟合（高偏差、低方差）是泛化的两大挑战。

## 2. 线性模型

### 2.1 线性回归
- **模型**：y = w^T x + b
- **损失函数**：均方误差 MSE = (1/n) * sum((y_i - y_hat_i)^2)
- **求解方法**：正规方程 w = (X^T X)^(-1) X^T y；梯度下降
- **评价指标**：MSE、RMSE、MAE、R^2

### 2.2 逻辑回归
- **用途**：二分类（也可扩展为多分类）
- **模型**：P(y=1|x) = sigma(w^T x)，其中 sigma(z) = 1/(1+e^(-z))
- **损失函数**：交叉熵损失
- **决策边界**：w^T x = 0，即 sigma = 0.5

## 3. 模型评估与选择

### 3.1 分类指标
- **准确率（Accuracy）**：(TP+TN)/(TP+TN+FP+FN)
- **精确率（Precision）**：TP/(TP+FP)——预测为正的样本中真正为正的比例
- **召回率（Recall）**：TP/(TP+FN)——真正为正的样本中被成功识别的比例
- **F1 分数**：精确率和召回率的调和平均，2*P*R/(P+R)
- **ROC-AUC**：ROC 曲线下面积，评估模型在不同阈值下的综合表现

### 3.2 交叉验证
- **K 折交叉验证**：将数据分为 K 份，轮换使用 K-1 份训练、1 份验证
- 提供比单次划分更稳健的性能估计
- 适用于中小规模数据集

### 3.3 过拟合与正则化
- **过拟合原因**：模型过于复杂、训练数据不足、特征过多
- **L1 正则化（Lasso）**：产生稀疏解，可用于特征选择
- **L2 正则化（Ridge）**：惩罚大权重，使模型更平滑
- **Dropout**（深度学习）：训练时随机丢弃部分神经元

## 4. 常见误区汇总

- 误区：准确率越高模型越好 → 事实：在不平衡数据集中，准确率可能误导（如 99% 负样本，全部预测负类就有 99% 准确率）
- 误区：训练集误差越小越好 → 事实：训练误差过小可能是过拟合，测试集表现才是关键
- 误区：特征越多越好 → 事实：多余特征增加计算量且可能导致过拟合，特征选择很重要
- 误区：R^2 越接近 1 越好 → 事实：过高 R^2 往往是过拟合信号，尤其在特征数接近样本数时
- 误区：正则化总会降低模型性能 → 事实：适当的正则化可以提高泛化能力，在测试集上表现更好

## 5. 关键概念速查

| 概念 | 一句话总结 |
|------|-----------|
| 偏差-方差权衡 | 简单模型高偏差低方差，复杂模型低偏差高方差 |
| 交叉验证 | K 折轮换，稳健估计泛化性能 |
| L1 vs L2 | L1 产生稀疏解（特征选择），L2 平滑权重 |
| F1 分数 | 不均衡数据下比准确率更合理的指标 |
| 梯度下降 | 迭代优化：w = w - lr * gradient，学习率是关键超参数 |
