# 数据结构算法训练路线

## 1. 概念定义

数据结构与算法训练路线用于把抽象的数据结构知识转化为可执行的编程训练计划。它面向人工智能课程中的工程基础部分，帮助学生补齐 Python/C/C++ 编程、算法复杂度、数据组织和问题建模能力。

本路线参考 shishujuan/data-structure-algorithms 的基础算法主题，并与本知识库已有的数学基础、AI 搜索算法、编程题库衔接。

## 2. 核心原理

算法训练应按“结构 -> 操作 -> 题型 -> 复杂度 -> 易错点”的顺序推进。

| 阶段 | 核心主题 | 训练目标 |
|------|----------|----------|
| 入门 | 数组、字符串、哈希表 | 掌握遍历、计数、去重、查找 |
| 基础结构 | 链表、栈、队列、堆 | 掌握指针/引用关系和受限操作 |
| 树结构 | 二叉树、BST、堆、Trie | 掌握递归、层序遍历、优先队列 |
| 图结构 | 邻接表、BFS、DFS、并查集 | 掌握连通性、搜索、最短路径建模 |
| 算法范式 | 二分、双指针、贪心、动态规划 | 掌握状态、选择、转移和边界 |
| 综合实践 | 蓝桥杯/课程项目题 | 用算法解决真实任务中的子问题 |

## 3. 示例说明

### 3.1 二分查找训练链

1. 在有序数组中查找目标值。
2. 查找第一个大于等于目标值的位置。
3. 查找最后一个小于等于目标值的位置。
4. 在旋转数组中查找最小值。
5. 用二分答案求“最小可行值”。

二分训练的重点不是背模板，而是明确区间含义和循环不变式。

### 3.2 图搜索训练链

1. 用邻接表存图。
2. 用 BFS 求无权图最短距离。
3. 用 DFS 求连通块数量。
4. 用并查集合并动态关系。
5. 在网格地图中处理障碍、边界和访问标记。

图搜索和 AI 中的状态空间搜索直接相关，后续可迁移到 A*、博弈搜索和规划问题。

## 4. 常见误区

- 误区：只会调用库函数就等于掌握算法。
  - 正确做法：至少要能解释数据结构的操作复杂度和适用场景。
- 误区：动态规划就是套公式。
  - 正确做法：先定义状态含义，再确定转移来源和初始化边界。
- 误区：BFS 和 DFS 可以随便替换。
  - 正确做法：BFS 适合最短层数，DFS 适合枚举路径、连通性和回溯搜索。

## 5. 关键要点

- 算法训练应优先覆盖复杂度、边界条件和错因分析。
- 数据结构是 AI 搜索、模型部署工程和编程题生成的基础支撑。
- 编程题库中的题目应标注知识点、难度、输入输出、参考思路和测试样例。
- 对基础薄弱学生，优先推送数组、哈希表、二分和栈队列；对进阶学生再推送图、DP、堆和并查集。

## 6. 推荐学习顺序

数组与字符串 -> 哈希表 -> 栈与队列 -> 链表 -> 二分查找 -> 排序 -> 递归与回溯 -> 树 -> 堆 -> 图搜索 -> 并查集 -> 动态规划 -> 综合题。
