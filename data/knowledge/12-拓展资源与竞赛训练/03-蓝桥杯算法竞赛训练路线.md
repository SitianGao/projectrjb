# 蓝桥杯算法竞赛训练路线

## 1. 概念定义

蓝桥杯算法竞赛训练路线用于把课程中的数据结构、算法分析和编程实践组织成阶段化训练任务。它适合放入个性化学习系统中，用于为学生推送不同难度的实操案例和编程题。

本路线参考 Qume2005/lanqiaobei_exam 这类蓝桥杯训练仓库的题库方向，并结合本项目现有 `11-编程题库` 进行扩展。

## 2. 核心原理

竞赛训练不是孤立刷题，而是围绕题型范式构建能力：

| 模块 | 典型题型 | 关键能力 |
|------|----------|----------|
| 基础语法 | 日期、进制、模拟、字符串处理 | 精确实现和边界处理 |
| 枚举模拟 | 暴力枚举、前缀和优化 | 规模分析与剪枝 |
| 搜索 | DFS、BFS、回溯、迷宫 | 状态设计与访问标记 |
| 数学 | 质数、最大公约数、组合计数 | 数学公式和快速判断 |
| 数据结构 | 栈、队列、堆、并查集 | 用结构降低复杂度 |
| 动态规划 | 背包、序列、路径计数 | 状态转移和初始化 |
| 图论 | 最短路、连通块、拓扑排序 | 图建模和路径分析 |

## 3. 示例说明

### 3.1 学生画像驱动的题目推荐

如果学生画像显示“Python 基础较弱、数学基础一般、目标是蓝桥杯省赛”，系统应优先推送：

1. 字符串处理、日期模拟、进制转换。
2. 前缀和、差分、双指针。
3. BFS 迷宫和 DFS 连通块。
4. 简单动态规划，如爬楼梯、最长上升子序列。

如果学生已经掌握基础语法，可推送：

1. 并查集维护连通关系。
2. 堆维护 Top-K 或任务优先级。
3. Dijkstra 最短路径。
4. 背包 DP 和区间 DP 入门题。

### 3.2 与 AI 课程的衔接

蓝桥杯训练中的搜索、图论和动态规划可以作为 AI 搜索算法的工程前置知识：

- BFS/DFS -> 状态空间遍历。
- Dijkstra/A* -> 路径规划。
- 动态规划 -> 最优子结构和强化学习价值迭代的直觉基础。
- 并查集/图连通性 -> 知识图谱、社群划分和关系建模的基础。

## 4. 常见误区

- 误区：竞赛题和人工智能课程无关。
  - 正确做法：竞赛题训练的是建模、复杂度和工程实现，能支撑 AI 系统开发。
- 误区：先学完所有算法再做题。
  - 正确做法：每学一个知识点就配套 2-3 道典型题，通过反馈修正理解。
- 误区：只保存题面，不保存错因。
  - 正确做法：题库要记录标签、难度、边界条件、常见错误和参考代码。

## 5. 关键要点

- 蓝桥杯题库适合作为个性化资源生成中的“代码类实操案例”来源。
- 编程题应覆盖模拟、搜索、数学、数据结构、DP 和图论六类。
- 推荐系统应根据学生画像动态调整题目难度。
- 每道题最好包含题面、输入输出、样例、思路、复杂度和参考实现。
