# 机器学习常见薄弱点与针对性突破

## 1. 线性回归常见薄弱点

### 1.1 易错概念
- **混淆正规方程与梯度下降的适用场景**：正规方程适合小数据（n < 10⁴），梯度下降适合大数据
- **忽略特征缩放对梯度下降的影响**：未归一化的特征会导致等高线呈椭圆，收敛缓慢
- **误以为 R² 越高越好**：R² 随特征数增加而单调不减，需要用 Adjusted R² 或交叉验证

### 1.2 针对性练习
1. 用正规方程和梯度下降分别求解同一数据集，对比结果和运行时间
2. 对比有/无特征缩放时梯度下降的收敛曲线
3. 分析残差图：如果残差呈漏斗形，说明存在异方差性

### 1.3 推荐复习资源类型
- `document`：重读损失函数推导和正规方程证明
- `code`：实现带正则化的 Ridge/Lasso 回归对比

---

## 2. 梯度下降常见薄弱点

### 2.1 易错概念
- **学习率选择不当**：过大震荡发散，过小收敛过慢
- **混淆批量/随机/小批量梯度下降**：BS=1（SGD）噪声大但快，BS=m（BGD）稳定但慢，BS=32~256（MBGD）折中
- **不理解局部最优与鞍点的区别**：高维空间中鞍点比局部最优更常见

### 2.2 针对性练习
1. 在二维二次函数上可视化不同学习率的梯度下降轨迹
2. 手动实现动量法（Momentum）和 Adam 优化器
3. 画出不同 batch_size 下的 loss 曲线，观察震荡幅度

### 2.3 推荐复习资源类型
- `exercise`：做梯度推导题（手算 + 代码验证）
- `code`：实现不同优化器的对比实验

---

## 3. 决策树常见薄弱点

### 3.1 易错概念
- **混淆 ID3/C4.5/CART 的划分准则**：ID3 用信息增益（偏向多值特征），C4.5 用信息增益率，CART 用 Gini
- **不理解剪枝的必要性**：不剪枝的决策树容易过拟合到每个训练样本
- **混淆 Bagging 和 Boosting 的差异**：Bagging 并行、降方差；Boosting 串行、降偏差

### 3.2 针对性练习
1. 手算一个小数据集的信息增益，画出决策树
2. 对比未剪枝 / 预剪枝 / 后剪枝 的树结构和泛化能力
3. 在同一数据集上对比随机森林（Bagging）和 XGBoost（Boosting）

### 3.3 推荐复习资源类型
- `document`：理清划分准则的数学定义
- `code`：调参实验（max_depth, min_samples_split, n_estimators）

---

## 4. 支持向量机常见薄弱点

### 4.1 易错概念
- **混淆线性可分与非线性的 SVM 推导**：硬间隔 → 软间隔（引入松弛变量 ξ） → 核方法（映射到高维）
- **不理解对偶问题的意义**：原始问题处理特征维度，对偶问题处理样本数维度；且对偶形式允许引入核函数
- **核函数选择无据**：线性核（特征多、样本少）、RBF 核（默认首选）、多项式核（需要特征交互）

### 4.2 针对性练习
1. 手推导硬间隔 SVM 的 KKT 条件
2. 在不同核函数下对比决策边界形状
3. 实验 C 参数（正则化系数）对间隔宽度的影响

### 4.3 推荐复习资源类型
- `document` + `exercise`：SVM 数学推导是高频薄弱点，需要反复练习

## 5. 神经网络基础常见薄弱点

### 5.1 易错概念
- **混淆前向传播和反向传播的维度**：手写矩阵求导时容易遗漏链式法则中的 Jacobian 转置
- **不理解激活函数的梯度特性**：Sigmoid 饱和区梯度接近 0（梯度消失），ReLU 在 x<0 时梯度为 0（死亡神经元）
- **混淆 epoch / batch / iteration 的关系**：1 epoch = 遍历全部数据 1 次；1 iteration = 处理 1 个 batch

### 5.2 针对性练习
1. 手算一个 2-3-1 网络的反向传播更新（全部手动推导）
2. 对比 Sigmoid / Tanh / ReLU / LeakyReLU 的训练速度和最终精度
3. 调参实验：学习率、batch_size、隐藏层宽度对训练的影响

### 5.3 推荐复习资源类型
- `code`：从零实现 MLP（不用框架），验证反向传播的正确性
- `reading`：阅读 Xavier/He 初始化的论文摘要，理解为什么要这样初始化

---

## 6. 通用薄弱诊断框架

| 症状 | 可能原因 | 推荐资源类型 |
|------|---------|------------|
| 公式会背但不会用 | 缺乏实战练习 | `exercise` + `code` |
| 代码能跑但不理解 | 理论概念不扎实 | `document` + `mindmap` |
| 单个知识点 OK，综合题不会 | 知识碎片化 | `mindmap` + `reading` |
| 学完就忘，反复看同一内容 | 缺少间隔复习 | `exercise`（主动回忆）+ `document` |
| 只会调包，不理解原理 | 缺少底层实现经验 | `code`（from scratch） |

> **使用建议**：本文件应与 `spaced-repetition-strategy.md` 配合使用——前者确定何时复习（when），本文件确定复习什么（what）和怎么复习（how）。
