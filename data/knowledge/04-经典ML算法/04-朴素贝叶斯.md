# 朴素贝叶斯

## 贝叶斯定理回顾

**贝叶斯定理**描述了基于相关条件的先验知识，某事件发生的概率：

$$P(C \mid X) = \frac{P(X \mid C) \cdot P(C)}{P(X)}$$

其中：
- $P(C \mid X)$ 是给定特征 $X$ 下类别 $C$ 的**后验**概率
- $P(X \mid C)$ 是给定类别 $C$ 下观测到特征 $X$ 的**似然**
- $P(C)$ 是类别 $C$ 的**先验**概率
- $P(X)$ 是**证据**（边缘似然），一个归一化常数

预测类别是使后验概率最大化的那个类别（最大后验估计，MAP）：

$$\hat{y} = \arg\max_{C} P(C \mid X) = \arg\max_{C} P(X \mid C) \cdot P(C)$$

$P(X)$ 被省略，因为对于给定输入，它在所有类别中都是常数。

## "朴素"条件独立性假设

直接计算 $P(X \mid C) = P(x_1, x_2, \dots, x_n \mid C)$ 对于高维数据来说是不可行的。**朴素**假设是：给定类别后，特征之间是**条件独立**的：

$$P(X \mid C) = P(x_1 \mid C) \cdot P(x_2 \mid C) \cdot \dots \cdot P(x_n \mid C) = \prod_{i=1}^{n} P(x_i \mid C)$$

这在现实世界中几乎总是不成立的——特征之间经常存在相关性。然而，朴素贝叶斯在实践中往往表现得非常出色，尤其是在文本分类中，原因如下：
- 后验概率的排序比其精确值更重要
- 独立性假设使得参数在有限数据上易于估计
- 相关特征倾向于"重复计数"证据，但其方向（指向正确类别）通常是一致的

完整的 MAP 决策规则变为：

$$\hat{y} = \arg\max_{C} P(C) \prod_{i=1}^{n} P(x_i \mid C)$$

在实践中，使用对数概率以避免数值下溢：

$$\hat{y} = \arg\max_{C} \left[ \log P(C) + \sum_{i=1}^{n} \log P(x_i \mid C) \right]$$

## 朴素贝叶斯的变体

### 高斯朴素贝叶斯

假设连续特征在每个类别中都遵循**高斯（正态）分布**：

$$P(x_i \mid C) = \frac{1}{\sqrt{2\pi\sigma_{C,i}^2}} \exp\left( -\frac{(x_i - \mu_{C,i})^2}{2\sigma_{C,i}^2} \right)$$

参数 $\mu_{C,i}$ 和 $\sigma_{C,i}$ 通过最大似然估计（样本均值和方差）从训练数据中估计。适用于特征为连续且大致服从正态分布的场景。

### 多项式朴素贝叶斯

将特征向量建模为计数（例如，文档中的词频）。似然为：

$$P(X \mid C) = \frac{(\sum_i x_i)!}{\prod_i x_i!} \prod_i p_{C,i}^{x_i}$$

其中 $p_{C,i}$ 是类别 $C$ 中特征 $i$ 的概率，估计如下：

$$p_{C,i} = \frac{N_{C,i} + \alpha}{N_C + \alpha n}$$

其中 $N_{C,i}$ 是类别 $C$ 中特征 $i$ 的计数，$N_C$ 是类别 $C$ 中所有特征的总计数，$n$ 是特征数量，$\alpha$ 是平滑参数。

主要应用场景：使用词频特征的**文本分类**（词袋模型）。

### 伯努利朴素贝叶斯

假设特征向量为二值（0 或 1）。似然为：

$$P(x_i \mid C) = p_{C,i}^{x_i} \cdot (1 - p_{C,i})^{(1 - x_i)}$$

适用于特征表示存在/缺失而非频率的场景。常见于短文本分类，其中单词是否出现比出现频率更重要。

### 补集朴素贝叶斯

多项式朴素贝叶斯的一个变体，使用每个类别的补集统计信息。旨在解决数据集不平衡问题。当不平衡严重时，标准多项式朴素贝叶斯倾向于偏向多数类；补集朴素贝叶斯可以纠正这一问题。

## 拉普拉斯平滑

如果某个特征值在训练数据中从未出现在某个类别中会怎样？没有平滑的情况下，$P(x_i \mid C) = 0$，这将使整个乘积归零。**拉普拉斯（加法）平滑**为所有特征-类别计数添加一个小计数 $\alpha$：

$$P(x_i \mid C) = \frac{\text{count}(x_i, C) + \alpha}{\text{count}(C) + \alpha \cdot d}$$

其中 $d$ 是不同特征值的数量。当 $\alpha = 1$ 时，即为标准拉普拉斯平滑；$\alpha < 1$ 称为 Lidstone 平滑。这确保了没有任何概率为零。

## 优点

- **极快的速度**：训练复杂度为 $O(Nd)$，预测复杂度为 $O(d)$。是最快的分类器之一。
- **小数据集上表现良好**：参数估计仅需极少的数据（仅需均值和方差）。
- **可扩展到高维数据**：维度对性能的影响不如基于距离的方法那么严重。
- **优雅地处理无关特征**：它们会获得接近均匀分布的概率，不会扭曲结果。
- **概率输出**：提供校准良好的概率（尤其在经过校准后）。
- **增量学习**：可以轻松地用新数据更新（sklearn 中的 partial_fit）。
- **可解释性**：可以检查 $P(x_i \mid C)$ 来了解哪些特征驱动了分类决策。

## 缺点

- **强烈的独立性假设**：在实践中很少成立。"身高"和"体重"等特征显然是相关的。
- **没有平滑时的零频率问题**：未见过的特征-类别组合会使后验概率归零。
- **在复杂结构化数据上不具竞争力**：深度学习和树集成方法在具有复杂交互的表格数据上通常优于朴素贝叶斯。
- **假设特定分布**：高斯朴素贝叶斯假设正态分布；拟合不佳会降低性能。
- **对特征缩放敏感**（高斯朴素贝叶斯）：方差较大的特征会占主导地位。
- **概率估计不佳**：虽然排序通常不错，但实际概率值可能校准不当（通常过于自信）。

## sklearn 示例：文本分类

```python
from sklearn.datasets import fetch_20newsgroups
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB, GaussianNB, BernoulliNB
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report, accuracy_score
from sklearn.pipeline import make_pipeline

# 加载文本数据（二分类：alt.atheism vs soc.religion.christian）
categories = ["alt.atheism", "soc.religion.christian"]
newsgroups = fetch_20newsgroups(subset="all", categories=categories,
                                 random_state=42)

X_train, X_test, y_train, y_test = train_test_split(
    newsgroups.data, newsgroups.target, test_size=0.2, random_state=42
)

# 流水线：向量化文本，然后分类
# 选项1：CountVectorizer + MultinomialNB（文本分类的标准方案）
pipeline = make_pipeline(
    CountVectorizer(stop_words="english", max_features=5000),
    MultinomialNB(alpha=1.0)  # 拉普拉斯平滑
)

pipeline.fit(X_train, y_train)
y_pred = pipeline.predict(X_test)

print(f"Accuracy: {accuracy_score(y_test, y_pred):.3f}")
print(classification_report(y_test, y_pred,
                             target_names=newsgroups.target_names))

# 检查每个类别中最有信息量的特征
nb = pipeline.named_steps["multinomialnb"]
vec = pipeline.named_steps["countvectorizer"]
feature_names = vec.get_feature_names_out()

for i, class_name in enumerate(newsgroups.target_names):
    top_indices = nb.feature_log_prob_[i].argsort()[-10:][::-1]
    top_words = [feature_names[j] for j in top_indices]
    print(f"\nTop words for {class_name}: {', '.join(top_words)}")
```

## 应用场景

### 垃圾邮件检测

朴素贝叶斯的经典应用。电子邮件的特征（单词、发件人、链接）用于计算 $P(\text{spam} \mid \text{email})$。结合 TF-IDF 加权的多项式朴素贝叶斯在标准数据集上可以达到 95% 以上的准确率。特征包括：像"免费"、"中奖"、"点击这里"等单词的出现情况、感叹号数量、发件人信誉等。

### 情感分析

将文本分类为正面、负面或中性。特征为 n-gram（1-3 个单词的序列）。朴素贝叶斯是一个强有力的基线模型，在标注数据有限的情况下，常常能与更复杂的模型相媲美。

### 文档分类

新闻分类、主题标注、体裁识别。多项式朴素贝叶斯是标准基线；补集朴素贝叶斯在不平衡的文档集合中效果更好。

### 医疗诊断

给定症状（特征），预测疾病（类别）。适用于分类症状（存在/不存在）。先验 $P(C)$ 可以来自疾病患病率数据。

### 实时分类

朴素贝叶斯非常适合实时或流式应用，因为其预测时间在亚毫秒级别：欺诈检测、聊天审核、推荐引擎。

## 三种主要变体对比

| 变体 | 数据类型 | 似然 | 最佳适用场景 |
|---------|-----------|------------|----------|
| 高斯朴素贝叶斯 | 连续型 | $P(x_i \mid C) \sim \mathcal{N}(\mu_{C,i}, \sigma^2_{C,i})$ | 通用连续特征 |
| 多项式朴素贝叶斯 | 计数/离散型 | $P(X \mid C) \propto \prod p_{C,i}^{x_i}$ | 文本、词频统计 |
| 伯努利朴素贝叶斯 | 二值型 | $p^{x_i} (1-p)^{1-x_i}$ | 存在/缺失特征 |

## 关键超参数 (sklearn)

| 参数 | 描述 |
|-----------|-------------|
| `alpha` | 加法（拉普拉斯/Lidstone）平滑参数（默认 1.0） |
| `fit_prior` | 是否从数据中学习类别先验（默认 True） |
| `class_prior` | 手动指定的类别先验（如果已知） |
| `var_smoothing` | （高斯朴素贝叶斯）为稳定性而加到所有方差上的最大方差比例 |
| `binarize` | （伯努利朴素贝叶斯）二值化特征的阈值 |
| `norm` | （补集朴素贝叶斯）是否按第二范数加权 |

## 何时选择朴素贝叶斯

朴素贝叶斯是正确选择的场景：
- 需要一个**快速基线**来为更复杂的模型做基准测试
- 训练数据**稀缺**（在数百条而非数百万条样本下表现良好）
- 特征在很大程度上是**独立**的（或者可以经过特征工程使其独立）
- 需要**实时预测**且延迟极低
- 可解释性很重要（检查单词-类别关联）
- 问题是**文本分类**（朴素贝叶斯在这方面仍然是表现最好的方法之一）
