# 强化学习：基础与核心算法

## 强化学习框架

强化学习 (RL) 是研究如何通过与环境交互来学习做出序列决策的领域。其基本循环为：

- **智能体 (Agent)** 观察环境的当前**状态** $s_t$。
- 它根据其**策略** $\pi$ 选择一个**动作** $a_t$。
- 环境转移到新状态 $s_{t+1}$ 并产生一个标量**奖励** $r_t$。
- 智能体的目标是最大化累积（折扣）奖励和：$G_t = \sum_{k=0}^\infty \gamma^k r_{t+k}$。

折扣因子 $\gamma \in [0, 1]$ 控制未来奖励相对于即时奖励的重视程度。

---

## 马尔可夫决策过程 (MDP)

环境被形式化为 MDP，由以下元组定义：

$$\mathcal{M} = (S, A, P, R, \gamma)$$

- $S$：状态集合。
- $A$：动作集合。
- $P(s' \mid s, a)$：状态转移概率（马尔可夫性质——未来仅依赖于当前状态和动作，而非历史）。
- $R(s, a, s')$：奖励函数。
- $\gamma$：折扣因子。

---

## 策略、价值与 Q 函数

**策略** $\pi(a \mid s)$：在状态 $s$ 下选择动作 $a$ 的概率。确定性策略将 $s$ 映射到 $a$。

**状态价值函数** $V^\pi(s)$：从状态 $s$ 出发并此后遵循 $\pi$ 的期望回报：

$$V^\pi(s) = \mathbb{E}_\pi\left[\sum_{t=0}^\infty \gamma^t r_t \;\middle|\; s_0 = s\right]$$

**动作价值 (Q) 函数** $Q^\pi(s, a)$：从状态 $s$ 出发，采取动作 $a$，然后遵循 $\pi$ 的期望回报：

$$Q^\pi(s, a) = \mathbb{E}_\pi\left[\sum_{t=0}^\infty \gamma^t r_t \;\middle|\; s_0 = s, a_0 = a\right]$$

---

## 贝尔曼方程

贝尔曼方程表达了状态的价值与后继状态价值之间的递归关系：

$$V^\pi(s) = \sum_{a \in A} \pi(a \mid s) \sum_{s' \in S} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V^\pi(s') \right]$$

对于 Q 函数：

$$Q^\pi(s, a) = \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma \sum_{a'} \pi(a' \mid s') Q^\pi(s', a') \right]$$

最优价值函数 $V^*$ 的**贝尔曼最优方程**（即从每个状态可获得的最大期望回报）：

$$V^*(s) = \max_{a} \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V^*(s') \right]$$

---

## 价值迭代与策略迭代

当 MDP 模型 $(P, R)$ 已知时，以下是两种基本的规划方法。

### 策略迭代

在两个步骤之间交替，直到收敛：

1. **策略评估：** 通过求解贝尔曼方程（迭代或直接求解）计算当前策略的 $V^\pi$。
2. **策略改进：** 对每个状态，设 $\pi(s) = \arg\max_a \sum_{s'} P(s' \mid s, a)[R + \gamma V^\pi(s')]$。

对于有限 MDP，策略迭代在有限步数内收敛。

### 价值迭代

将评估和改进合并为单次更新：

$$V_{k+1}(s) = \max_a \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V_k(s') \right]$$

当 $k \to \infty$ 时收敛到 $V^*$。每次迭代比策略迭代计算效率更高。

---

## Q-Learning：离线策略 TD 控制

Q-learning (Watkins, 1989) 直接从经验中学习最优 Q 函数，无需环境模型。它是一种**离线策略 (off-policy)** 算法——它学习最优策略，而与用于探索的行为策略无关。

**更新规则（表格形式）：**

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

- $\alpha$：学习率。
- 括号中的项是 **TD 误差**——自助目标与当前估计之间的差异。
- 使用 $\max_{a'} Q(s', a')$（根据当前估计的最佳动作），而不管下一步实际采取的动作——这使其成为离线策略。

---

## SARSA：在线策略 TD 控制

SARSA（State-Action-Reward-State-Action）是 Q-learning 的在线策略对应算法：

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma Q(s', a') - Q(s, a) \right]$$

关键区别：它使用 $Q(s', a')$，其中 $a'$ 是当前策略**实际采取**的动作，而非最大化动作。这使得 SARSA 更加保守——它考虑了探索策略的次优选择，这可以更安全（例如，避免 Q-learning 智能体会乐观地导航的风险路径）。

---

## 探索与利用

一个基本的权衡：利用已知的好动作来立即获得奖励，还是探索未知的动作以发现更好的策略。

### $\epsilon$-贪心

以概率 $1 - \epsilon$ 采取贪心动作 $\arg\max_a Q(s, a)$。以概率 $\epsilon$ 采取随机动作。简单但探索方式均匀且效率低下。

### Softmax（玻尔兹曼）探索

从概率分布中采样动作：

$$\pi(a \mid s) = \frac{\exp(Q(s, a) / \tau)}{\sum_{a'} \exp(Q(s, a') / \tau)}$$

温度 $\tau$ 控制随机性：高 $\tau$ 更具探索性，低 $\tau$ 更贪心。$\tau$ 通常随时间退火。

### UCB（上置信界）

对于赌博机问题，选择上置信界最高的动作：

$$a_t = \arg\max_a \left[ Q_t(a) + c \sqrt{\frac{\ln t}{N_t(a)}} \right]$$

奖励项鼓励尝试具有高不确定性的动作（访问次数少）。在深度 RL 中，类似的思想出现在 Noisy Networks 等方法中。

---

## 深度 Q 网络 (DQN)

Mnih 等人（2015）将 Q-learning 与深度神经网络结合，在 Atari 游戏上实现了超人类的表现。两个关键创新使其训练稳定：

### 经验回放

将转移 $(s, a, r, s')$ 存储在回放缓冲区中。训练时，从该缓冲区中采样随机小批量数据。这：
- 打破了连续样本之间的相关性（使训练更接近监督学习的独立同分布假设）。
- 允许每个经验被多次重用，提高采样效率。

### 目标网络

维护一个单独的网络 $Q_{\text{target}}$，其参数 $\theta^-$ 更新频率较低（例如，每 $C$ 步更新一次，或通过 Polyak 平均更新）。TD 目标使用目标网络：

$$\text{target} = r + \gamma \max_{a'} Q_{\text{target}}(s', a')$$

这通过防止目标在每一步都发生变化来稳定训练——否则会产生类似于追逐自己尾巴的"移动目标"问题。

---

## 策略梯度与 REINFORCE

基于价值的方法学习 $Q$ 并推导出策略（例如 $\epsilon$-贪心）。策略梯度方法直接优化策略参数 $\theta$，以最大化期望回报 $J(\theta)$。

### 策略梯度定理

$$\nabla_\theta J(\theta) = \mathbb{E}_\pi \left[ \nabla_\theta \log \pi_\theta(a \mid s) \cdot Q^\pi(s, a) \right]$$

### REINFORCE（蒙特卡洛策略梯度）

使用实际回报 $G_t$ 作为 $Q^\pi$ 的无偏（但高方差）估计：

$$\theta \leftarrow \theta + \alpha \sum_{t} \nabla_\theta \log \pi_\theta(a_t \mid s_t) \cdot G_t$$

收集完整回合，计算回报，然后更新。方差高但简单。从 $G_t$ 中减去基线 $b(s)$（通常为 $V(s)$）可以在不引入偏差的情况下减少方差。

---

## Actor-Critic 方法

Actor-Critic 结合了基于价值和基于策略的方法：
- **Actor ($\pi_\theta$)：** 策略——决定采取什么动作。通过策略梯度更新。
- **Critic ($V_\phi$ 或 $Q_\phi$)：** 价值函数——评估 Actor 的动作有多好。通过 TD 学习更新。

TD 误差 $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$ 作为 Actor 更新的优势估计：

$$\theta \leftarrow \theta + \alpha \nabla_\theta \log \pi_\theta(a_t \mid s_t) \cdot \delta_t$$

---

## 关键算法演进

| 算法 | 年份 | 关键创新 |
|-----------|------|----------------|
| **DQN** | 2015 | 深度网络 + 经验回放 + 目标网络 |
| **A3C** | 2016 | 异步并行 Actor-Critic；熵奖励用于探索 |
| **PPO** | 2017 | 裁剪代理目标函数；稳定、采样高效、广泛使用 |
| **SAC** | 2018 | 最大熵 RL 与自动温度调节；连续控制的最先进方法 |

PPO 因其简单性和鲁棒性成为大多数现代 RL 应用的默认选择。SAC 在连续动作空间（机器人、运动控制）中表现卓越。

---

## 应用场景

- **游戏对弈：** AlphaGo/AlphaZero（超人类的围棋、国际象棋、将棋水平），Atari，Dota 2，星际争霸 II。
- **机器人学：** 灵巧操作、运动控制、无人机控制、仿真到真实迁移。
- **推荐系统：** 将序列推荐建模为 MDP；最大化长期用户参与度。
- **自动驾驶：** 高速公路和城市场景下的不确定性决策。
- **大语言模型：** RLHF（基于人类反馈的强化学习）使用 PPO 和基于人类偏好训练的奖励模型微调 LLM。
- **金融：** 投资组合优化、交易执行、做市。

## OpenAI Gym 示例（FrozenLake 上的 Q-Learning）

```python
import gymnasium as gym
import numpy as np

env = gym.make("FrozenLake-v1", is_slippery=False)
Q = np.zeros([env.observation_space.n, env.action_space.n])
alpha, gamma, epsilon = 0.1, 0.99, 0.1

for episode in range(10000):
    state, _ = env.reset()
    done = False
    while not done:
        if np.random.random() < epsilon:
            action = env.action_space.sample()
        else:
            action = np.argmax(Q[state])
        next_state, reward, terminated, truncated, _ = env.step(action)
        done = terminated or truncated
        # Q-learning 更新
        Q[state, action] += alpha * (
            reward + gamma * np.max(Q[next_state]) - Q[state, action]
        )
        state = next_state

print("Trained Q-table:")
print(Q)
```
