# 神经网络基础 —— 核心知识点

## 1. 概念定义

人工神经网络（ANN）是由大量简单处理单元（神经元）相互连接构成的计算模型，灵感来源于生物神经网络。

## 2. 基本结构

### 2.1 神经元（Perceptron）

$$y = f(\sum_{i=1}^{n} w_i x_i + b)$$

其中 $f$ 为激活函数，$w_i$ 为权重，$b$ 为偏置。

### 2.2 常见激活函数

| 激活函数 | 公式 | 特点 |
|---------|------|------|
| Sigmoid | $\sigma(x) = \frac{1}{1+e^{-x}}$ | 输出(0,1)，有梯度消失问题 |
| Tanh | $\tanh(x) = \frac{e^x-e^{-x}}{e^x+e^{-x}}$ | 输出(-1,1)，零中心化 |
| ReLU | $\max(0, x)$ | 计算快，缓解梯度消失 |
| Leaky ReLU | $\max(0.01x, x)$ | 解决 ReLU 的"死亡神经元" |

### 2.3 前向传播

数据从输入层 → 隐藏层 → 输出层，逐层计算。

### 2.4 反向传播（Backpropagation）

利用链式法则计算每一层参数的梯度：

$$\frac{\partial L}{\partial w_{ij}^{(l)}} = \frac{\partial L}{\partial a_j^{(l)}} \cdot \frac{\partial a_j^{(l)}}{\partial w_{ij}^{(l)}}$$

## 3. 训练要点

### 3.1 权重初始化
- **Xavier**：适合 Sigmoid/Tanh
- **He**：适合 ReLU 系

### 3.2 正则化
- **L1/L2 正则化**：在损失函数中增加权重大小的惩罚项
- **Dropout**：训练时随机丢弃一部分神经元
- **Batch Normalization**：对每层输入进行标准化

### 3.3 学习率调度
- 初始阶段可用较大的学习率
- 接近收敛时减小学习率

## 4. 常见架构

- **MLP**（多层感知机）：全连接
- **CNN**（卷积神经网络）：图像处理
- **RNN/LSTM/GRU**：序列数据
- **Transformer**：注意力机制，NLP 和 CV 都适用

## 5. 常见误区

- ❌ 层数越多效果越好 → ✅ 需要配合残差连接等技巧
- ❌ 不需要数据预处理 → ✅ 归一化/标准化很重要
- ❌ Batch Norm 只是加速训练 → ✅ 也有轻微正则化效果

## 6. 关键要点

- 理解前向传播和反向传播是核心
- ReLU 系激活函数是当前默认选择
- 权重初始化方法影响训练稳定性
- 过拟合时尝试 Dropout、正则化或更多数据
