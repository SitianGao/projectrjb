# CNN（卷积神经网络）—— 核心知识点

## 1. 概念定义

卷积神经网络（CNN）是一种专门处理具有网格结构数据（如图像）的深度学习架构，核心特征是权重共享和局部连接。

## 2. 核心组件

### 2.1 卷积层（Convolution Layer）

用多个可学习的滤波器（卷积核）在输入上滑动，每个滤波器产生一个特征图（feature map）。

**特点**：
- **局部连接**：每个神经元只连接输入的一个局部区域
- **权重共享**：同一个滤波器在整个输入上共享权重
- **参数高效**：大幅减少参数量

### 2.2 池化层（Pooling Layer）

对特征图进行下采样，降低空间维度。

- **Max Pooling**：取窗口内的最大值（最常用）
- **Average Pooling**：取窗口内的平均值
- **Global Average Pooling**：整张特征图取平均

### 2.3 全连接层（FC Layer）

将卷积/池化后的特征图展平，进行最终的分类或回归。

## 3. 经典架构演进

| 架构 | 年份 | 核心创新 |
|------|------|---------|
| LeNet-5 | 1998 | CNN 鼻祖，手写数字识别 |
| AlexNet | 2012 | ReLU + Dropout + GPU，ImageNet 冠军 |
| VGGNet | 2014 | 深层 + 小卷积核（3×3） |
| GoogLeNet | 2014 | Inception 模块，多尺度特征 |
| ResNet | 2015 | 残差连接，解决了深层网络退化问题 |
| DenseNet | 2017 | 密集连接，特征复用 |

## 4. 关键设计原则

### 4.1 感受野（Receptive Field）
网络中某层输出特征图上的像素点在原始输入上映射的区域大小。

### 4.2 通道数设计
- 浅层：较少通道，提取低级特征（边缘、纹理）
- 深层：较多通道，提取高级语义特征

### 4.3 1×1 卷积
用于调整通道数（降维/升维）和增加非线性。

## 5. 训练技巧

- **数据增强**：随机裁剪、翻转、颜色抖动
- **Transfer Learning**：复用预训练模型的浅层特征
- **Batch Normalization**：加速训练、缓解梯度问题

## 6. 常见误区

- ❌ CNN 只能用于图像 → ✅ 也用于文本（字符级 CNN）、音频、时间序列
- ❌ 层数越深越好 → ✅ 需要残差连接等技巧配合
- ❌ 大卷积核更好 → ✅ 小卷积核堆叠可以获得相同的感受野且参数更少

## 7. 关键要点

- 卷积核的权重共享是 CNN 高效的关键
- 池化层提供平移不变性
- ResNet 的残差连接是深层网络的标配
- 预训练 + 微调是实践中的标准范式
