# CNN（卷积神经网络）—— 核心知识点

## 1. 概念定义

卷积神经网络（Convolutional Neural Network, CNN）是一种专门处理具有网格结构数据（如图像、音频频谱、视频帧）的深度学习架构。CNN 的两大核心特征是**权重共享**和**局部连接**，使其在参数量和计算效率上远优于全连接网络。

### 1.1 为什么需要 CNN？

如果使用全连接网络处理一张 224×224×3 的 RGB 图像：
- 输入维度：150,528
- 假设第一个隐藏层有 1024 个神经元
- 参数量：150,528 × 1024 ≈ **1.54 亿参数**（仅第一层！）

CNN 通过以下方式解决这一灾难性参数爆炸：
- **局部连接**：每个神经元只连接输入的一个小区域（如 3×3 = 9 个连接，而非 150,528 个）
- **权重共享**：同一个卷积核在整个输入上滑动，参数与输入尺寸解耦

## 2. 数学基础：卷积运算

### 2.1 离散二维卷积

$$(I * K)(i, j) = \sum_{m} \sum_{n} I(i+m,\; j+n) \cdot K(m, n)$$

其中 $I$ 是输入图像，$K$ 是卷积核（滤波器）。

**示例**：一个 3×3 卷积核在 5×5 输入上的操作：
```
输入 (5×5):      卷积核 (3×3):    输出 (3×3):
┌──────────┐    ┌─────────┐      ┌──────────┐
│1 2 3 0 1│    │ 1  0 -1│      │ -5 -2  3│
│4 5 6 1 0│ *  │ 1  0 -1│  =   │ -3  0  1│
│7 8 9 0 1│    │ 1  0 -1│      │  1  2 -3│
│2 3 4 5 6│    └─────────┘      └──────────┘
│1 0 1 0 1│
└──────────┘
```
> 以上为简化的垂直边缘检测卷积核（Sobel-like）

### 2.2 输出尺寸计算

$$H_{out} = \left\lfloor \frac{H_{in} + 2P - K}{S} \right\rfloor + 1$$

其中：
- $H_{in}/H_{out}$：输入/输出高度
- $K$：卷积核大小
- $P$：Padding（填充）
- $S$：Stride（步长）

### 2.3 关键变体

**1×1 卷积 (Pointwise Convolution)**：仅改变通道数（降维/升维），不改变空间尺寸。计算量仅为普通卷积的 1/9（相比3×3）。

**Depthwise Separable Convolution（MobileNet 核心）**：
1. Depthwise Conv：每个通道单独卷积（空间维度）
2. Pointwise Conv：1×1 跨通道融合

参数量从 $K^2 \cdot C_{in} \cdot C_{out}$ 降至 $K^2 \cdot C_{in} + C_{in} \cdot C_{out}$，约减少至原来的 $\frac{1}{C_{out}}$。

**空洞卷积 (Dilated/Atrous Convolution)**：在卷积核元素间插入间隙，在不增加参数的情况下扩大感受野。膨胀率 $r=2$ 时，3×3 卷积核的感受野等价于 5×5。

## 3. 核心组件

### 3.1 卷积层（Convolution Layer）

用多个可学习的滤波器（卷积核）在输入上滑动，每个滤波器产生一个特征图（feature map）。

**特点**：
- **局部连接**：每个神经元只连接输入的一个局部区域（感受野）
- **权重共享**：同一个滤波器在整个输入上共享权重 → 平移等变性
- **参数高效**：参数量 = $K \times K \times C_{in} \times C_{out}$，与输入尺寸无关

**学习的层次化特征：**
```
浅层卷积核 → 边缘、纹理、颜色斑块
    ↓
中层卷积核 → 形状、局部模式（眼睛、轮子、窗户）
    ↓
深层卷积核 → 物体部件、完整语义概念（人脸、汽车）
```

### 3.2 池化层（Pooling Layer）

对特征图进行下采样，降低空间维度。池化层**没有可学习参数**。

| 类型 | 操作 | 特点 |
|------|------|------|
| **Max Pooling** | 取窗口内的最大值 | 最常用，保留最显著特征 |
| **Average Pooling** | 取窗口内的平均值 | 更平滑，保留背景信息 |
| **Global Average Pooling** | 整张特征图取平均 | 替代Flatten+FC，大幅减少参数 |
| **Adaptive Pooling** | 指定输出尺寸，自动调整窗口 | 允许任意输入尺寸 |

**池化的作用：**
- 降低空间维度 → 减少计算量和参数量
- 扩大感受野 → 深层神经元能看到更大的输入区域
- 提供局部平移不变性 → 小的位置变化不影响输出

### 3.3 全连接层（FC Layer）

将卷积/池化后的特征图展平为一维向量，通过线性变换 + 激活函数进行最终的分类或回归。

**注意**：现代架构（如 ResNet 最后的 Global Average Pooling + 单层 FC）倾向减少全连接层的使用。ViT 等 Transformer 架构甚至不使用 FC 分类头，直接在 CLS token 上接 LayerNorm + Linear。

### 3.4 激活函数

| 函数 | 公式 | 特点 |
|------|------|------|
| **ReLU** | $f(x)=\max(0,x)$ | 简单高效，但存在神经元死亡问题（x<0 梯度为0）|
| **LeakyReLU** | $f(x)=\max(0.01x, x)$ | 解决死亡ReLU问题，负区间有微小梯度 |
| **GELU** | $x\cdot\Phi(x)$ | Transformer/CV 现代架构的默认选择 |
| **SiLU/Swish** | $x\cdot\sigma(x)$ | EfficientNet中使用，效果优于ReLU |

### 3.5 归一化层

| 类型 | 归一化维度 | 适用场景 |
|------|-----------|---------|
| **BatchNorm** | 跨 batch 维度 | CNN 标配，大 batch 效果好 |
| **LayerNorm** | 跨特征维度 | Transformer 标配，batch size 不敏感 |
| **InstanceNorm** | 跨空间维度（逐样本逐通道）| 风格迁移，生成任务 |
| **GroupNorm** | 通道分组归一化 | 小 batch（≤8）时的 BatchNorm 替代 |

## 4. 经典架构演进

| 架构 | 年份 | 参数量 | 核心创新 |
|------|------|--------|---------|
| LeNet-5 | 1998 | 60K | CNN 鼻祖，Conv→Pool→Conv→FC 范式 |
| AlexNet | 2012 | 60M | ReLU + Dropout + GPU并行，深度学习复兴的标志 |
| VGGNet-16 | 2014 | 138M | 深层 + 全是 3×3 小卷积核堆叠，简单统一 |
| GoogLeNet/Inception-v3 | 2014-15 | 23M | Inception模块：多尺度并行卷积+1×1降维 |
| ResNet-50/101/152 | 2015 | 25-60M | **残差连接**：$H(x)=F(x)+x$，训练152层成为可能 |
| DenseNet-121 | 2017 | 8M | 密集连接：每层接收前面所有层的特征图 |
| SENet | 2017 | — | **通道注意力**：学习各通道的重要性权重 |
| MobileNet-v2/v3 | 2018-19 | 3-5M | 深度可分离卷积 + 倒残差 + SE，移动端优化 |
| EfficientNet-B0~B7 | 2019 | 5-66M | 复合缩放：同时扩大深度、宽度、分辨率 |
| RegNet | 2020 | — | 网络设计空间搜索，提供设计原则 |
| ConvNeXt | 2022 | — | "现代化CNN"：借鉴Swin Transformer设计，性能对标ViT |

### 残差连接详解

$$
\mathbf{y} = \mathcal{F}(\mathbf{x}, \{W_i\}) + \mathbf{x}
$$

**为什么有效？**
1. **梯度高速公路**：反向传播时梯度可以直接通过恒等映射路径传回浅层，缓解梯度消失
2. **学习残差更容易**：网络只需学习 $F(x) = H(x) - x$（输入与目标的差异），而非完整映射
3. **恒等映射的默认行为**：如果深层没有额外信息增益，网络可以简单地将 $F(x)$ 推向 0

**Bottleneck 设计（ResNet-50/101/152）**：
```
输入 (256通道)
  ↓ 1×1 Conv → 64通道（降维）
  ↓ 3×3 Conv → 64通道（核心计算）
  ↓ 1×1 Conv → 256通道（升维）
  ↓ + 输入（跳跃连接）
输出 (256通道)
```
参数量仅为直接 3×3 卷积的 ~17%。

## 5. 训练 CNN 的最佳实践

### 5.1 数据增强（现代标配）

| 方法 | 说明 | 何时使用 |
|------|------|---------|
| RandomResizedCrop | 随机裁剪后 resize | 分类任务标配 |
| RandomHorizontalFlip | 50% 概率水平翻转 | 自然图像通用 |
| ColorJitter | 亮度/对比度/饱和度/色调扰动 | 防止颜色过拟合 |
| MixUp | 两张图像+标签按比例混合 | 提升泛化和鲁棒性，几乎必用 |
| CutMix | 图像区域替换 | 配合 MixUp 交替使用 |
| RandAugment | 随机选择 N 个增强操作，强度 M | 自动增强的首选 |

### 5.2 学习率调度

- **Warmup**：前 5-10 个 epoch 线性增加学习率，防止初期不稳定
- **Cosine Annealing**：余弦曲线衰减，比阶梯式衰减更平滑
- **OneCycleLR**：先升后降的单周期策略，收敛更快
- **ReduceLROnPlateau**：验证指标停滞时自动降低学习率

### 5.3 优化器选择

| 优化器 | 适用场景 | 说明 |
|--------|---------|------|
| **AdamW** | 通用推荐 | Adam + 解耦权重衰减，绝大多数任务的默认选择 |
| **SGD + Momentum** | 追求极致精度 | 需要精细调参但可能泛化更好 |
| **LAMB** | 大批量训练 | 超大 batch size (32K+) 时使用 |

### 5.4 正则化技巧

- **Dropout** (全连接层后)：随机失活神经元，防止过拟合
- **DropPath / Stochastic Depth**：随机丢弃整个残差块（训练深层网络时使用）
- **Label Smoothing**：将 one-hot 标签从 $[0,0,1,0]$ 平滑为 $[0.01,0.01,0.95,0.01]$
- **Weight Decay**：L2 正则化，AdamW 中与学习率解耦
- **EMA (指数移动平均)**：推理时使用参数的指数平滑版本，通常带来 0.2-1% 精度提升

### 5.5 迁移学习策略

```
数据量        推荐策略
─────────────────────────────────────
<1K 样本      冻结所有卷积层，只训练分类头
1K-10K 样本   冻结浅层，微调最后 1-2 个 stage
>10K 样本     全模型微调（较小学习率，如 1e-4）
海量数据      从头训练（但 COCO 上 ImageNet 预训练仍然有帮助）
```

## 6. 常见误区

- ❌ **CNN 只能用于图像** → ✅ 也用于文本分类（TextCNN）、音频（频谱图 + CNN）、时间序列预测、视频理解（3D CNN）
- ❌ **层数越深越好** → ✅ 需要残差连接、合适的初始化和归一化配合，否则深层网络退化
- ❌ **大卷积核更好** → ✅ 小卷积核（3×3）堆叠可用更少参数获得相同感受野，且中间有更多非线性
- ❌ **BatchNorm 总是最好** → ✅ 小 batch（≤4）时 GroupNorm/LayerNorm 更稳定
- ❌ **预训练权重一定有帮助** → ✅ 如果预训练数据（如 ImageNet）与目标数据分布差异很大（如医学影像、遥感），收益有限

---

## 7. 关键要点

- 卷积核的**权重共享**是 CNN 高效的核心，参数与输入尺寸解耦
- CNN 学习**层次化特征**：浅层→边缘纹理，中层→局部模式，深层→语义概念
- **残差连接**是现代深层网络（ResNet 及以后）的标配设计
- 池化层提供局部**平移不变性**并降低计算量
- **1×1 卷积**用于通道降维/升维，是高效架构的关键组件
- **预训练 + 微调**是实践中的标准范式，适用于绝大多数任务
- **数据增强**（尤其是 MixUp/CutMix）对泛化能力的提升至关重要
- **AdamW + Cosine Annealing + Warmup** 是可靠的默认训练方案

> **建议核实**：具体网络架构的性能数据和排名以 PapersWithCode / ImageNet 官方基准为准。网络实现细节建议参考 torchvision 和 timm 的官方文档。
