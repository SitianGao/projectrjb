# Q-Learning 与 Deep Q-Network (DQN)

## 1. 强化学习基础概念

强化学习（Reinforcement Learning, RL）是机器学习的一个重要分支，研究智能体（Agent）如何在环境（Environment）中通过交互学习最优策略。

### 核心要素

- **状态（State, S）**：智能体所处的环境状态
- **动作（Action, A）**：智能体可以采取的行为
- **奖励（Reward, R）**：环境对智能体动作的反馈
- **策略（Policy, π）**：状态到动作的映射
- **价值函数（Value Function, V(s)）**：状态 s 的长期期望回报
- **Q 函数（Q(s, a)）**：在状态 s 执行动作 a 的长期期望回报

### 马尔可夫决策过程（MDP）

强化学习问题通常建模为马尔可夫决策过程：
- 状态转移概率：P(s'|s, a)
- 折扣因子 γ：平衡短期与长期奖励
- 目标：最大化累积折扣奖励 E[Σ γ^t * r_t]

## 2. Q-Learning 算法

### 基本思想

Q-Learning 是一种无模型的时序差分（Temporal Difference, TD）学习算法。通过学习 Q(s, a) 函数，智能体可以在每个状态选择最优动作。

### Q 值更新公式

```
Q(s, a) ← Q(s, a) + α [r + γ * max_a' Q(s', a') - Q(s, a)]
```

其中：
- α：学习率
- γ：折扣因子
- r：即时奖励
- max_a' Q(s', a')：下一状态最大 Q 值

### 算法流程

1. 初始化 Q 表（通常为全零）
2. 对于每一幕（episode）：
   - 获取初始状态 s
   - 重复直到终止：
     - 根据 ε-greedy 策略选择动作 a
     - 执行 a，观察奖励 r 和新状态 s'
     - 更新 Q(s, a)
     - s ← s'

### ε-Greedy 探索策略

以概率 ε 随机选择动作（探索），以概率 1-ε 选择 Q 值最大的动作（利用）。ε 通常随时间衰减。

## 3. Deep Q-Network (DQN)

### 为何需要 DQN

传统 Q-Learning 使用 Q 表存储状态-动作值，当状态空间很大或连续时（如图像输入），Q 表无法存储。DQN 使用**深度神经网络**来近似 Q 函数。

### 核心创新

#### 3.1 经验回放（Experience Replay）

- 将智能体的经验 (s, a, r, s') 存储在回放缓冲区
- 训练时从缓冲区随机采样小批量数据
- **好处**：打破数据相关性、提高样本效率

#### 3.2 目标网络（Target Network）

- 维护两个网络：Q 网络（在线）和 Target Q 网络
- 目标网络参数定期从 Q 网络复制
- 目标值计算：r + γ * max_a' Q_target(s', a')
- **好处**：稳定训练过程，避免 Q 值估计的发散

### DQN 损失函数

```
Loss = E[(r + γ * max_a' Q_target(s', a') - Q(s, a))²]
```

## 4. DQN 改进算法

### 4.1 Double DQN

- **问题**：DQN 在选择和评估动作时使用同一网络，导致 Q 值过高估计
- **方案**：用 Q 网络选择动作，用 Target 网络评估该动作
- 目标值：r + γ * Q_target(s', argmax_a' Q(s', a'))

### 4.2 Dueling DQN

- 将 Q 网络分为两个流：
  - **价值流 V(s)**：状态本身的价值
  - **优势流 A(s, a)**：动作相对于平均的优势
- Q(s, a) = V(s) + A(s, a) - mean(A(s, ·))
- **好处**：更有效地学习状态价值

### 4.3 Prioritized Experience Replay

- 不是均匀采样，而是根据 TD 误差大小分配采样概率
- 误差大的经验更有"学习价值"，优先采样
- 使用重要性采样权重修正偏差

## 5. 实践要点

### 超参数建议
- 学习率：1e-3 到 1e-4
- 折扣因子 γ：0.95 到 0.99
- ε 衰减：从 1.0 逐渐衰减至 0.01-0.1
- 回放缓冲区大小：10000 到 1000000
- 目标网络更新频率：每 100-10000 步

### 常见问题与解决方案
- **训练不稳定**：减小学习率、增大目标网络更新间隔
- **收敛慢**：增大回放缓冲区、调整探索率
- **Q 值爆炸**：使用梯度裁剪、Double DQN
